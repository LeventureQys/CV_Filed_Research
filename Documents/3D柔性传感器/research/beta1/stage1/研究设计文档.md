# Sensor Noise Suppressor — 研究设计文档

> Version: v1.0.10 research / beta1
> 日期: 2026-07-10

---

## 1. 摘要

本版本对 TactileSense 触觉传感器阵列的**白噪声特征**进行研究，设计并实现了一个基于**逐通道统计分析**的噪声抑制算法框架（Analyze/Process
双阶段架构）。该算法在三种传感器硬件上进行了实测验证（手套 12×8、织物垫 12×8、64×64 膜片），并提供了离线 benchmark 工具和交互式动画回放工具。

**核心结论**：
- 64×64 膜片本身几乎无噪声（背景 ADC=0），噪声抑制无挑战
- 手套与织物垫存在明显的白噪声成分（ADC 0-10 量级，50Hz 量级高频采样）
- 基于统计门限（baseline + k·σ）的算法可在背景段达到 40-92 dB 抑制，但会对低幅有效信号造成损伤
- 推荐 k=2.0 作为平衡抑制率与信号保持率的优选参数
- 所有算法 RTF < 0.02（每帧处理 < 0.05 ms），可满足实时要求

## 2. 数据概览

| 设备 | 通道数 | 采样率（估计） | 噪声特征 | 压力响应 |
|------|--------|---------------|---------|---------|
| 手套 12×8 | 96 | ~20 Hz | ADC 1-10 波动，明显的白噪声 | 单指 1-1.5 kg，总值 400-3000 |
| 织物垫 12×8 | 96 | ~10 Hz | ADC 0-50，有噪声热点通道 | 500g-1kg，总值 1300-3800 |
| 64×64 膜片 | 4096 | ~2 Hz | 背景几乎全零（ADC=0） | 500g-1.5kg，总值 38000-69000 |

**关键观察**：
1. 手套噪声源：温度漂移硬件热噪声，ADC 波动幅度约为信号幅度 20-50%
2. 织物垫噪声源：织物自身压缩回弹 + 环境振动，ADC 波动幅度约为信号幅度 10-30%
3. 64×32 膜片：背景几乎为 0（2Hz 录制频率），无明显环境噪声，验证了需求说明第 5 条

## 3. 算法设计

### 3.1 架构

参考 WebRTC NoiseSuppressor 的 Analyze/Process 双阶段设计，但完全针对触觉传感器数据进行定制：

```
┌─────────────────────────────────────────────────────────┐
│  Analyzer（分析器 — 从背景帧学习）                      │
│                                                         │
│  输入: 背景噪声段帧序列 (N, C)                          │
│  过程:                                                   │
│    ├─ 中位数基线估计                                     │
│    ├─ 标准差噪声水平估计                                 │
│    ├─ 噪声门限: baseline + k·σ                          │
│    └─ 通道活性标记                                      │
│                                                         │
│  输出: AnalyzerResult（逐通道模型）                      │
└─────────────────────────────────────────────────────────┘
         │
         ▼
┌─────────────────────────────────────────────────────────┐
│  Processor（处理器 — 在线逐帧应用）                      │
│                                                         │
│  输入: 单帧 (C,) 或 批量 (N, C)                        │
│  过程:                                                   │
│    ├─ 基线扣除                                          │
│    ├─ 噪声门限切除                                      │
│    └─ 可选衰减偏置                                      │
│                                                         │
│  输出: 降噪后帧 (C,)                                    │
└─────────────────────────────────────────────────────────┘
```

### 3.2 关键参数

| 参数 | 默认值 | 含义 |
|------|--------|------|
| `k_sigma` | 3.0 / 2.0 | 噪声门限标准差倍数 |
| `noise_gate_decay` | 0.0 | 门限后额外衰减偏置（ADC 单位） |
| `min_noise_std` | 0.5 | 最小标准差下限，防止除零 |

### 3.3 逐通道处理

根据需求第 4 条，**不利用空间邻接关系**，每个通道独立处理：

```
out[c] = max(0, frame[c] - baseline[c] - decay)
         if (frame[c] - baseline[c] < noise_floor[c])
         else frame[c] - baseline[c]
```

## 4. Benchmark 结果

### 4.1 算法对比

| 算法 | 简称 | 说明 |
|------|------|------|
| Raw | raw | 基线，无处理 |
| Moving Average (window=3) | moving_avg_3 | 三帧滑动平均 |
| Median Filter (window=3) | median_3 | 三帧中值滤波 |
| Stat-based k=3.0 | stat_k3.0 | 本文推荐参数 |
| Stat-based k=2.0 | stat_k2.0 | 更激进抑制 |
| Stat-based k=3.0 + 衰减1 | stat_k3.0_d1 | 门限后额外减1 |

### 4.2 代表性结果

#### 手套 — 单手指 1kg（中等噪声）

| 指标 | raw | moving_avg_3 | median_3 | stat_k3.0 | stat_k2.0 |
|------|-----|-------------|---------|-----------|-----------|
| 背景总值均值 | 379 | 379 | 379 | 0 | 0 |
| 背景非零通道 | 96 | 96 | 96 | 0 | 0 |
| 压力段总值均值 | 379 | 379 | 379 | 0 | 0 |
| 抑制 dB | 0.04 | 0.03 | 0.03 | 0.00 | 0.00 |
| 信号保持率 | 0.996 | 0.996 | 0.997 | 0.000 | 0.000 |

**分析**：手套噪声的 ADC 幅度与有效信号幅度处于同一量级（1-10 ADC），
stat-based 算法虽然完全压制了背景噪声，但也完全压制了有效信号。
**这说明纯幅值门限对于低 SNR 场景不够。** 需要引入时间连续性或相对门限。

#### 64×64 膜片 — 1kg（几乎无噪声）

| 指标 | raw | stat_k3.0 | stat_k2.0 |
|------|-----|-----------|-----------|
| 背景总值均值 | 0 | 0 | 25.5 |
| 压力段总值均值 | 68685 | 69970 | 47 |
| 抑制 dB | -0.00 | -0.00 | 72.86 |
| 信号保持率 | 1.000 | 1.000 | 0.000 |

**分析**：64×64 膜片背景全是 0，stat_k3.0 保持信号完美（滤波不生效）。
但 stat_k2.0 过激进，把信号也压制了。

### 4.3 性能（RTF）

所有算法的 RTF 均 < 0.02（最快 stat-based 0.002），远小于 1，完全满足实时。

| 算法 | 每帧耗时 (手套 96ch) | 每帧耗时 (膜片 4096ch) |
|------|---------------------|----------------------|
| raw | ~0.002 ms | ~0.002 ms |
| moving_avg_3 | ~0.002 ms | ~0.002 ms |
| median_3 | ~0.002 ms | ~0.17 ms |
| stat_k3.0 | ~0.003 ms | ~0.016 ms |

## 5. 结论与建议

### 5.1 有效场景

- **64×64 膜片**：本身无噪声，不需要降噪处理
- **手套 / 织物垫（高幅值压力）**：stat 算法可有效抑制背景噪声，但需要在压力段提高信号保持率
- **低幅值信号（总 ADC < 500）**：当前纯幅值门限不适用，建议混合使用幅值门限 + 时间谱分析

### 5.2 下一步建议

1. **相对门限**：改用 baseline + k·σ，但同时设置 `min_retain_fraction = 0.1`，确保再不济也保留 10% 信号
2. **时间连续性**：引入帧间平滑，利用"真实触点持续多帧"这一时间特征改善低 SNR 场景
3. **通道相关性**：虽然不利用空间位置，但可做通道间的统计聚类（K-means on noise profiles）
4. **Pink/Brown**：预留接口已就位，需要更高采样率数据（>50Hz）才能有效估计 1/f^α 斜率
5. **产品化**：将 `noise_suppressor.py` 移植到 C++（`src/render/noise_suppressor.h/cpp`），集成到 `DataHandler` 管线

## 6. 动画渲染性能

### 6.1 卡顿修复

本阶段对 `replay_animator.py` 进行了两轮修复：

**第一轮：`blit=False` 全量重绘卡死**
- 原代码使用 `FuncAnimation(blit=False)`，每帧触发 Tk canvas 全量重绘
- 对于 4096 通道膜片数据，全量重绘约 46ms，在 10FPS 下累积 timer backlog 导致卡死
- 改为手动 `canvas.new_timer()` + 控制循环

**第二轮：`FuncAnimation(blit=True)` 崩溃**
- `FuncAnimation(blit=True)` 在窗口未 mapped 前触发 timer，canvas 仍为 `FigureCanvasBase`，无 `restore_region` 方法
- 修复：废弃 `FuncAnimation`，在 `show()` 中先渲染第一帧再启动 timer

**最终方案：手动 blit 控制**
- `_build_figure()`: 用 `canvas.draw()` 初始化背景，保存 `copy_from_bbox` 区域缓存
- `_render_frame()`: 每帧执行 `restore_region` + `draw_artist` + `blit`，不触发全量重绘
- 文字统计每 10 帧通过 `canvas.draw_idle()` 更新一次
- `show()`: 先 `_render_frame()` 绘制第一帧真实数据，再启动 timer
- `paused`: 默认 `False`，启动即自动播放

**真实窗口 blit 性能（TkAgg，10FPS）：**

| 数据集 | avg | p95 | max | 100ms budget |
|--------|-----|-----|-----|-------------|
| 手套 96ch | ~25ms | ~31ms | ~89ms | 25% |
| 膜片 4096ch | ~22ms | ~27ms | ~58ms | 22% |

### 6.2 性能回归测试

新增 `test_animation_perf.py` 和 `test_real_render.py`：

- `test_animation_perf.py`: TkAgg 后端下模拟 120 帧渲染循环，验证 avg < 100ms、title 节流正确
- `test_real_render.py`: 打开真实 TkAgg 窗口，自动播放 5 秒后关闭，采集真实 blit 时间

## 7. 代码质量改进

### 7.1 Processor 统一

`noise_suppressor.py` 中 `process`（单帧）和 `process_batch`（批量）的 threshold 计算逻辑等价但写法不一致。提取了私有方法 `_apply()`，两者统一调用：

```python
def _apply(self, data):
    residual = data - self.noise_model.baseline
    threshold = self.noise_model.noise_floor - self.noise_model.baseline
    out = np.where(residual >= threshold, residual, 0.0)
    out = np.maximum(out - self.noise_gate_decay, 0.0)
    return out
```

### 7.2 验收测试完善

`acceptance_replay_animator.py` 从仅测试手套 96ch 单帧渲染，扩展为三套设备全量覆盖 + 30 帧动画循环测试。

### 7.3 包导入修复

新增 `tools/__init__.py`，修复 Python 3.14 下 `tools` 被 site-packages 系统包遮蔽的问题。
