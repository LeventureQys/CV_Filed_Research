- 每轮研究结束后，被证明不合适的算法 / 路线，必须：

- 归档的 README 必须写明：该路线废弃原因

### 0.3 实验记录是完整时间线

- `beta1/stage2/实验记录.md` 必须记录：
  - 每一轮尝试做了什么
  - 为什么被否决 / 为什么继续
  - 关键量化指标（RMSE, SRR, BNSR, peak retention 等）
- 方便后续研究时回溯："这方法已经试过了，问题在这里"

### 0.4 总报告必须带图

- 每次修改 `总报告.md`，必须包含：
  - **模拟数据切片对比图**（至少 2 张）
  - **真实数据切片对比图**（至少 glove / fabric / film64 各 1 张）
  - 每张图下面一句话结论
- 图中必须包含 **原始数据 vs 当前算法处理后的数据** 的直接对比
- 如果有之前的算法，应该**在同一张图里拉对比**

### 0.5 新算法的测试流程

1. 先在**模拟数据**上做前期测评
2. 确认模拟数据上结果有意义后，再上**真实设备数据**
3. 模拟数据必须覆盖多种 layout（12×8 / 32×16 / 64×64）和多种噪声类型（glove-like / membrane-like）

### 0.6 项目范围约束

- 所有 Stage2 工作必须在 `beta1/stage2/` 目录下完成
- **不允许涉及 v1.0.10 目录以外的任何代码**

## 1. 当前任务目标

找到一个降噪算法，满足：

1. 把同一时刻整个 layout 的所有数据看成整体，做成分分析
2. 在模拟数据和真实数据上都成立
3. 不能明显删除真信号（glove / fabric 上 SRR 不能过低）
4. 不能只靠 film64 的视觉效果自我说服

### 1.1 重要修正：双轨策略（2026-07-11）

经过多轮实验已确认：**64×64 膜片和手套/织物垫的噪声物理来源不同，不能用同一个算法解决。**

| 设备 | 噪声类型 | 背景特征 | 当前状态 |
|------|----------|----------|----------|
| 64×64 膜片 | 空间孤立散粒（偶发，时序无关） | 无压力通道 = 0 ADC | **已解决** — TemporalGate |
| 手套 | 全域基线噪声（每通道 ~8 ADC 持续存在） | 全通道有基线，压力全程存在 | 待攻克 |
| 织物垫 | 全域基线噪声（每通道 ~50-250 ADC 持续存在） | 全通道有基线，压力全程存在 | 待攻克 |

**后续研究必须分设备处理，不要再尝试寻找通用统一算法。**

## 2. 已确认的约束

### 2.1 不能逐通道独立处理

WienerGate 的问题已确认：逐通道独立建模不匹配真实整体结构。

### 2.2 不能只看模拟数据效果

所有新路线必须先过模拟数据定量测评，再过真实数据。

### 2.3 不能接受"真能量被整体删掉"

当前所有已尝试路线（Wiener, SVD hard, PCA, NMF）在 glove/fabric 上 SRR 都过低。

### 2.4 白噪声假设按"小噪声"处理

当前先不考虑大规模白噪声，按传感器实际噪声水平（σ 0.5-5 ADC）建模。

### 2.5 模拟数据必须覆盖多种 layout 和噪声类型

不能只测 64×64。

### 2.6 模拟压力必须是团块，不是单 cell

压力模拟必须是**多个通道组成的团块（cluster/blob）**，不能是单通道点压。

### 2.7 每轮至少 5 组模拟数据

评测用模拟数据集每轮至少覆盖 5 组不同场景（不同位置、不同振幅、不同噪声水平）。

### 2.8 Noise Suppressor 方案不保证适用

Stage1 的 WebRTC NS 式逐通道 noise suppressor 算法**不一定适合触觉传感器阵列**。如果这个路线走不动，必须敢于放弃并寻找新的路线。

### 2.9 空间关系可能比预想的更重要

"目前估计是和空间无关，但是实际上从结果来看，还是有一定关系的" — 虽然逐通道独立处理被否定了，但通道间的空间关系（不仅仅是物理位置，还包括整体统计结构）可能比最初假设的更重要。

## 4. 当前认知（重要）

经过多轮尝试，现在已知：

1. **逐通道独立处理的模型是错误的** — 这已被 Wiener 路线证明
2. **整帧整体分析的方向是正确的** — PCA/NMF 路线证实有效结构确实存在
3. **但简单的整体重建（PCA/NMF）会把真信号一起压扁**
4. **EdgeGate 在膜片上有效但边缘会误杀真信号** — 已确认
5. **膜片用时序一致性可以近乎完美解决** — 已确认 (99.5% 保留, 0% 误激活)
6. **手套/织物垫的核心困难不是算法而是数据** — 实测 CSV 中压力全程存在，无法获取纯背景帧学基线

## 5. 后续研究建议

### 5.1 膜片: 继续优化 TemporalGate

膜片降噪已基本可用。后续可做:
- 参数调优（threshold, min_consecutive, leaky rate）
- C++ 移植到主项目

### 5.2 手套/织物垫: 需要解决基线获取问题

继续攻击手套/织物垫的方向建议:
- 尝试让设备先采集一段无压力背景帧
- 或使用运行最小值追踪器在线估计噪声底噪
- 或探索帧间差分方法（压力变化比噪声平滑）

## 6. 结果判定标准

新路线至少要同时满足：

1. 模拟数据上 SRR ≥ 0.80（不能再全部压在 0.6 以下）
2. 真实 glove / fabric 上**不能明显删掉真信号**
3. 对比图进入 `总报告.md`，含原始 vs 处理后，并在实验记录中留下量化结果
