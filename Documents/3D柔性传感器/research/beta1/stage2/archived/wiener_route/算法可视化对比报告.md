## 2. 各图关键观察

### 2.1 模拟数据 (synthetic_blob)

#### blob_single_center
- **Original**: 全通道覆盖白噪声底噪（基底 ~15 ADC），中心有清晰高斯压力团块 (500 ADC)
- **WienerGate k=1.0**: 背景噪声几乎完全清除，压力团块完整保留，边缘清晰
- **WienerGate k=1.5**: 略保守，团块边缘有轻微衰减（k 越大越保守）
- **StatGate k=1.0**: 同样清除了背景噪声，但压力团块边沿有轻微剪切（硬门限的锯齿残留）
- **Spatial**: 不处理基线，噪声毫无变化；团块被高斯平滑轻微"晕开"
- **Hybrid**: 先硬切后平滑，效果接近 WienerGate 但有不必要的高斯光晕

**结论**: WienerGate 在此场景最忠实——噪声消除且信号形态完整。

#### blob_two / blob_five_palm
- 多点压力场景下 WienerGate 信号保持优势更明显
- Spatial 的团化在多点时视觉上更明显——各点之间出现"连接桥"（false correlation）
- Hybrid 的 hard gate 边缘锯齿在低对比度团块上尤为突出

#### blob_large_area
- 大面积接触时，Spatial 表现不差（因为接触面积大，平滑不损失太多信息）
- 但 WienerGate 仍然消除了所有背景噪声，输出更干净
- Hybrid 因平滑而看起来更"柔和"，但这是人为的团化效果

#### blob_weak_high_noise
- **关键测试场景**: 信号 amplitude=120, 噪声 σ=12, SNR 极低
- **WienerGate**: 压力团块隐约可见（软增益保留了弱信号），背景噪声大幅降低
- **StatGate**: 团块几乎不可见（弱信号被硬门限切除）
- **Spatial**: 噪声纹丝不动，团块完全淹没在噪声里
- **Hybrid**: 硬切后的剩余信号被平滑"涂抹"到周围，产生肉眼可见的虚假纹路

**结论**: 低 SNR 下 WienerGate 的软增益优势最明显——保守保留微弱信号，而硬门限直接归零。

### 2.2 真实设备数据

#### glove_1kg (手套, 12x8)
- **Original**: 每个通道都有背景基线 (~8 ADC)，按压区在左上到右下呈带状
- **WienerGate**: 背景基线完全清除，按压信号清晰，信号保留度高
- **StatGate**: 按压信号偏弱（硬门限切了边缘），残留背景噪声
- **Spatial**: 输出和原始几乎一模一样！高斯平滑对 96ch 低频数据效果极微弱
- **Hybrid**: 效果接近 WienerGate 但信号偏弱

**结论**: 手套数据的"信号 + 白噪声"模型完全成立。WienerGate 表现最优。

#### fabric_500g (织物垫, 12x8)
- **Original**: 基线更高 (~240 ADC)，全覆盖大面积压力(砝码), 各通道差异明显
- **WienerGate**: 基线去除后保留了每个通道的压力特征，无团化
- **StatGate**: 部分通道信号被过度消减
- **Spatial**: 同样几乎无效果

**结论**: WienerGate 忠实呈现了各通道的真实压力分布。

#### film64_1kg (64x32 膜片, 64x64)
- **Original**: 基线极低 (~17 ADC)，压力信号细腻, 空间分布复杂
- **WienerGate**: 有效去除了低噪声水平下的散粒噪声，保留了压力图案的细节
- **StatGate**: 在此低基线数据上效果不错（因为 baseline≈0, 不需要基线减法）
- **Spatial**: 团化效果在此高分数据上最明显——压力图案被"模糊"了
- **Hybrid**: StatGate 后高斯平滑，产生了"Spatial 式的团化"——边缘过渡区出现了虚假信号

**结论**: 膜片的低基线使其不适配"基线+噪声"模型。WienerGate 效果 OK 但不如手套显著。
建议 64×64 膜片使用 WienerGate 配合小 k_sigma (~0.5)。

## 3. 算法优劣最终判定

```
              噪声清除  信号保真  无团化  抗低SNR  真实数据适用
WienerGate      A        A        A      A        手套/织物
StatGate        B+       B-       A      C        已知基线场景
Spatial         F        D        F      F        无    
Hybrid          B        B-       D      B-       无(已废弃)
```

### 3.1 旧算法最终评估

| 算法 | 定性 | 致命缺陷 |
|------|------|----------|
| **StatGate** | 在理想数据上可用 | 硬门限——真实数据上必然切碎压力边界 |
| **Spatial** | 对 96ch 几乎无效；对 4096ch 团化严重 | 空间平滑制造虚假信号，从不压制噪声 |
| **Hybrid** | 综合评分看似最高，实际失真严重 | 继承了两者的缺陷：硬切+团化 = 最差组合 |

### 3.2 旧算法的理论性错误

Spatial 和 Hybrid 的根本问题在于**混淆了信号复原和图像后处理**：
- 触觉传感器的每通道值有物理含义（力值 ADC），不能像图像像素一样随意平滑
- 高斯平滑本质是将邻域均值作为该点估计——当邻域包含零值噪声通道时，该点信号被稀释
- 当邻域包含强信号通道时，该点信号被虚假增强（SRR > 1 的根源）
- 这在图像去噪中是可接受的视觉效果，但在触觉传感器中是不可接受的**物理测量失真**

## 4. WienerGate 参数建议

| 数据类型 | k_sigma | 理由 |
|----------|---------|------|
| 手套 (12x8, 96ch) | 1.0 | 基线明确，噪声稳定，标准参数即可 |
| 织物垫 (12x8, 96ch) | 1.0-1.5 | 基线较高，略保守避免切除弱信号 |
| 64×64 膜片 (4096ch) | 0.5-0.8 | 基线极低，需要更宽松的门限保留细节 |
| 通用 | 1.0 | 默认安全值 |
