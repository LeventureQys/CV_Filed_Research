# PCA 子空间降噪路线说明

> 日期: 2026-07-11  
> 状态: 新主线原型  
> 对比图: `output_pca/pca_*.png`

## 1. 为什么重做

之前走过两条路：

1. **WienerGate / 维纳滤波**
   - 在模拟数据上好看
   - 在真实数据上不稳定
   - 根因: 它默认每个通道都可以独立地用 `signal + white_noise` 模型解释

2. **SVD hard（单帧 2D 截断）**
   - 比 WienerGate 更接近正确方向
   - 但它仍然有两个问题：
     - 它是在一帧 2D 矩阵内部做截断，隐含了“按行/按列低秩”的假设
     - 它没有利用整段真实数据去学习“这个 layout 的主要成分长什么样”

用户提出的关键建议是：

> 把同一时刻整个 layout 的所有 cell 当成一个整体，做成分分析。

这意味着：
- 一帧不是若干独立通道
- 一帧是一个高维向量 `x ∈ R^C`
- 多帧数据组成 `X ∈ R^(T×C)`
- 应该在 **整帧向量空间** 里学习主成分，而不是对单帧 2D 图做硬截断

## 2. 新路线是什么

新路线是：**PCA 子空间降噪**。

### 2.1 思想

把每一帧都看成一个长度为 `C` 的向量：

```
x_t = [cell_1, cell_2, ..., cell_C]
```

整段记录就变成：

```
X = [x_1; x_2; ...; x_T]   ∈ R^(T×C)
```

然后学习这样一个事实：

- **真实压力信号** 在整个 layout 上是有结构的，维度很低
- **噪声** 在整个 layout 上是散的、无结构的，维度很高

因此可以在 PCA 空间里分离它们：

- 前几个主成分 = 主要压力模式
- 后面大量小成分 = 噪声、微扰、随机抖动

### 2.2 处理流程

1. 背景段学习基线（对手套/织物垫）
2. 对整段数据做 baseline subtract + whitening
3. 用多帧数据做 SVD / PCA，得到主成分基
4. 处理单帧时，把单帧投影到 PCA 子空间
5. 在成分空间里做 **软收缩**（不是硬切）
6. 再投影回原空间

## 3. 为什么这比 SVD hard 更合理

### 3.1 SVD hard 的问题

SVD hard 做的是：

```
单帧矩阵 M (rows×cols)
M = UΣV^T
只保留前 r 个奇异值
```

这个方法的问题不是“完全错”，而是它太粗：

1. **它只看一帧**
   - 不知道真实数据长期的主要变化模式是什么
   - 容易把某一帧里偶然强的局部结构也当作主成分

2. **它默认行/列方向有意义**
   - 对 12×8、64×64 这种阵列当然有物理布局
   - 但你提的更关键：先把整帧视作整体向量，再看整体成分

3. **它是硬截断**
   - 低于阈值的成分被完全置零
   - 和 StatGate 一样，本质上还是“硬切”的思路，只不过切的是奇异值

### 3.2 PCA 子空间的优势

PCA 子空间方法：

- 不是单帧学结构，而是 **多帧共同学结构**
- 学到的是“这个设备、这段记录下，主要压力变化模式有哪些”
- 对单帧只保留这些稳定主模式
- 对小成分做软收缩，不是直接清零

换句话说：

| 方法 | 学谁的结构 | 抑噪方式 |
|------|------------|----------|
| WienerGate | 单通道噪声模型 | 通道级软增益 |
| SVD hard | 单帧 2D 结构 | 奇异值硬截断 |
| **PCA 子空间** | 多帧整体 layout 主模式 | 成分空间软收缩 |

## 5. 当前结论

现在还不应该说“PCA 就已经完全解决了问题”，但可以明确三点：

1. **方向比 WienerGate 更对**
   - 因为它终于不把 cell 当独立通道了
   - 它是按整帧 layout 学主模式

2. **方向也比 SVD hard 更合理**
   - 因为它学的是“多帧共同子空间”，不是“单帧硬截断”

3. **下一步应继续往“子空间 + 软收缩 + 稳定主模式学习”走**
   - 而不是继续在 StatGate / Spatial / WienerGate 上微调参数

## 6. 下一步建议

我建议下一轮继续做三件事：

1. **定量评估 PCA 子空间路线**
   - 和 WienerGate / SVD hard 统一打分
   - 看真实数据和模拟数据是否同时受益

2. **加入更合理的收缩函数**
   - 当前只是简单 PCA 子空间 + Wiener-like shrink
   - 可以改成对每个主成分做自适应 shrinkage

3. **把背景段 / 非背景段分离得更干净**
   - 尤其是真实 glove / fabric 记录，背景帧和施压帧的划分会直接影响学到的主空间

## 7. 现阶段判断

如果现在问“怎么办”，我的判断是：

> **不要再把重点放在 WienerGate 或 SVD hard 上。**  
> **下一条主线应该切到 PCA 子空间降噪。**

因为它更符合你提出的核心要求：

> 同一时刻把整个 layout 当一个整体来做成分分析。
