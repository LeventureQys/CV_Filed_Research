# 触觉传感器阵列降噪评估指标设计文档

> Stage: beta1 / Stage2
> 日期: 2026-07-10

---

## 1. 概述

本阶段针对 64×64 膜片传感器（4096 通道）的降噪算法评估，提出一套**有监督评估指标体系**。与 Stage1 的弱监督方法（仅使用背景/压力段分离）不同，本阶段使用**模拟数据**——知道每个通道的真实信号值（ground truth），从而实现更精确的定量评估。

## 2. 指标体系

### 2.1 信号保真度指标

#### 2.1.1 均方根误差 (RMSE)

衡量降噪后信号与 ground truth 之间的平均偏差：

```
RMSE = sqrt(mean((x_pred - x_true)^2))
```

其中 x_true 为无噪声的 ground truth 信号，x_pred 为降噪后的信号。

**单位**：ADC 单位
**范围**：[0, +∞)，越小越好
**适用**：全帧、压力区域、背景区域分别计算

#### 2.1.2 信噪比 (SNR)

传统信噪比定义，衡量信号能量与噪声能量的比值：

```
SNR = 10 * log10( var(x_true) / mean((x_pred - x_true)^2) )
     = 10 * log10( var(x_true) / MSE )
```

**单位**：dB
**范围**：(-∞, +∞)，越大越好
**注意**：当 ground truth 为全零（背景区域）时，var(x_true)=0，SNR 无定义，此时改用 2.1.3。

#### 2.1.3 背景噪声抑制比 (BNSR, Background Noise Suppression Ratio)

专门衡量背景区域（ground truth 为 0 的区域）的噪声残留：

```
BNSR = 10 * log10( var(noise_input) / var(noise_output) )

其中 noise_input = x_input - x_true（输入噪声）
     noise_output = x_pred - x_true（残留噪声）
```

对于背景区域 x_true = 0，简化为：

```
BNSR = 10 * log10( var(x_input_bg) / var(x_pred_bg) )
```

**单位**：dB
**范围**：(-∞, +∞)，越大越好（正值表示背景噪声被有效抑制）

#### 2.1.4 信号保持率 (Signal Retention Rate, SRR)

衡量压力区域中信号幅值的保持程度：

```
SRR = mean(|x_pred_stress|) / mean(|x_true_stress|)
```

**单位**：无量纲比值
**范围**：[0, 1]，越接近 1 越好
**注意**：SRR < 1 表示信号被衰减；SRR > 1 表示噪声残留增强了虚假信号

#### 2.1.5 结构相似性指数 (SSIM)

参考图像领域的 SSIM，评估降噪后信号在**空间结构**上的保持度。将 64×64 帧视为灰度图：

```
SSIM(x, y) = (2*μ_x*μ_y + C1)(2*σ_xy + C2) / ( (μ_x² + μ_y² + C1)(σ_x² + σ_y² + C2) )
```

其中 μ、σ 为均值和方差，C1、C2 为稳定常数。

**特别说明**：对于触觉传感器，SSIM 衡量的是压力分布的"形貌"保持程度——触点位置、大小、边界清晰度。这是纯逐通道统计无法衡量的空间维度。

**单位**：无量纲
**范围**：[-1, 1]，越接近 1 越好

### 2.2 空间域指标

#### 2.2.1 触点质心偏移 (Centroid Shift)

识别的触点区域质心与 ground truth 触点质心的欧氏距离：

```
CentroidShift = sqrt((cx_pred - cx_true)^2 + (cy_pred - cy_true)^2)
```

其中 (cx, cy) 为压力值加权质心：
```
cx = sum(x * w) / sum(w),  cy = sum(y * w) / sum(w),  w = pressure_value
```

**单位**：像素
**范围**：[0, +∞)，越小越好
**意义**：降噪算法不应导致触点的空间位置漂移

#### 2.2.2 触点面积保持率 (Contact Area Retention)

压力高于阈值（如 max_value * 0.1）的像素数比值：

```
AreaRetention = area_pred_stress / area_true_stress
```

**单位**：无量纲
**范围**：[0, +∞)，越接近 1 越好

### 2.3 时域指标

#### 2.3.1 帧间平滑度 (Temporal Smoothness)

衡量帧间过渡的自然程度，评估降噪后是否引入帧间抖动：

```
TempSmooth = mean(|x_pred(t) - x_pred(t-1)|) / mean(|x_true(t) - x_true(t-1)|)
```

**单位**：无量纲
**范围**：[0, +∞)，越接近 1 越好
**意义**：TempSmooth > 1 表示算法引入了额外的帧间噪声/抖动

### 2.4 综合指标

#### 2.4.1 综合评分 (Composite Score, CS)

将主要指标归一化后加权求和，用于快速横向对比：

```
CS = w1 * SNR_norm + w2 * SRR + w3 * SSIM + w4 * (1 - CentroidShift / max_shift)
```

默认权重：w1=0.25, w2=0.25, w3=0.3, w4=0.2

其中 SNR_norm = (SNR - SNR_min) / (SNR_max - SNR_min) 为归一化到 [0,1] 的信噪比。

## 3. 评估流程

```
┌─────────────────────────────────────────────┐
│  1. 生成模拟数据（ground truth + 噪声）      │
│     ├─ 确定触点位置和压力值                  │
│     ├─ 生成 ground truth 帧序列              │
│     └─ 叠加噪声（白噪声 + 可选粉红噪声）     │
├─────────────────────────────────────────────┤
│  2. 运行降噪算法                             │
│     ├─ 用背景帧训练 Analyzer                 │
│     └─ 用 Processor 处理含噪帧               │
├─────────────────────────────────────────────┤
│  3. 计算各项指标                             │
│     ├─ 计算 RMSE / SNR / BNSR               │
│     ├─ 计算 SRR / SSIM                      │
│     ├─ 计算 CentroidShift / AreaRetention   │
│     └─ 计算 TempSmooth / CompositeScore     │
├─────────────────────────────────────────────┤
│  4. 输出评估报告                             │
│     ├─ 控制台摘要                            │
│     └─ 详细 CSV / JSON 结果                 │
└─────────────────────────────────────────────┘
```

## 4. 注意事项

### 4.1 噪声特征

传感器噪声特征通过实际数据观察得到：
- 白色高斯噪声，幅度 ADC 0-10（手套），0-50（织物垫），0（64×64 膜片）
- 基线漂移（温度相关），低频慢变
- 各通道独立（无空间相关性噪声）

模拟数据应真实反映这些特征。

### 4.2 分区域评估

评估时至少分三个区域分别计算：
1. **背景区域**：没有压力、ground truth 全零的区域
2. **压力区域**：有压力的触点区域
3. **边界区域**：触点与非触点的过渡带

不同区域的指标权重不同（背景区看重 BNSR，压力区看重 SRR/SSIM，边界区看重 CentroidShift）。
