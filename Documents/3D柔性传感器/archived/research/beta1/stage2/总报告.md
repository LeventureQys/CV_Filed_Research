## 1. 膜片方案: SpatioTemporal（最终版）

### 原理

```
spatial_mask  = max_across_all_frames >= 10 ADC → closing(1) → 压力团块区域
temporal_mask = leaky_counter(threshold=3, min_cons=5) → 时序持续性
output        = spatial_mask AND temporal_mask → 保留原值，否则归零
```

- **空间判据**: 排除孤立持续低值噪音（如 ch806 = 6 ADC 被归零）
- **时序判据**: 保留边缘真实压力（如边缘 422 ADC 被保留）

### 实测结果

| 指标 | 数值 |
|------|------|
| >100 ADC 压力信号丢失 | **0** |
| 孤立噪声通道归零 | **110 / 4096** |
| ch806 (r12 c38, 6 ADC) | **正确归零** |
| 边缘通道 (422-433 ADC) | **全部保留** |

## 2. 手套/织物垫: 待攻克

所有基于逐通道阈值/时序/空间的方法在手/织物垫上均无效。
根本原因: 实测 CSV 中压力全程存在，无法获取纯背景帧学习每通道基线。

需要"先采背景再施压"的数据获取方式，或用运行最小值追踪器在线估计噪声底噪。

## 4. 废弃路线

全部归档在 `archived/`:

| 路线 | 废弃原因 |
|------|----------|
| WienerGate | 逐通道模型不匹配 |
| StatGate/Spatial/Hybrid | 硬切/团化/失真 |
| SVD hard | 单帧硬截断 |
| PCA 子空间 | whitening 削弱真信号 |
| NMF 时序 | 重建压缩残差 |
| EdgeGate | 边缘过杀 |
| TemporalGate | 无法处理孤立持续低值 |
