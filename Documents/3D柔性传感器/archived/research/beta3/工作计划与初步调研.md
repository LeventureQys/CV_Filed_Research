# beta3 工作计划与初步调研

> 日期：2026-07-13  
> 输入认知：膜片零压力可稳定在 0；织物类采集存在背景 bias；膜片受压边缘微弱值属于串扰候选  
> 本轮目标：完成问题重定义、横向方案比较和后续工作计划，不实现最终算法

> 仿真实施状态：已完成两组可复现实验与横向比较，结果见 `仿真研究报告.md`；结论仍需实物数据验证，不作为最终算法。

## 0. 用户确认后的研究边界

1. 不要求快速敲击和滑动，只研究长期稳定压力。
2. 织物垫主要研究局部压力；64×64 膜片同时研究局部压力和全局压力。
3. 当前真值来自直接放置砝码，不具备同步高精度测力计，只能进行定性降噪、稳态重复性和相对一致性评估。
4. 嵌入式不修饰传感器数据，当前上报值作为原始 ADC 观测。
5. 优先目标是总力稳定，单 Cell 稳定作为定位异常和构建总力的基础指标。

## 1. 三项工作拆分

| 工作包 | 核心问题 | 本轮输出 | 后续实验输出 |
|---|---|---|---|
| WP1 膜片算法重评 | 已知边缘小值是串扰后，现有 SpatioTemporal 是否还有价值 | 算法定位、保留部分、废弃部分和优化方向 | 串扰模型、候选算法横评和真实数据指标 |
| WP2 数据方案复核 | beta2 stage2 的补充采集是否仍值得执行 | 保留、修改、降级和新增实验清单 | 可用于串扰、偏置和力值研究的数据集 |
| WP3 力值稳定调研 | 如何减少标定后力值跳动，卡尔曼是否合适 | 候选算法、推荐顺序、适用边界和评估方法 | 砝码弱真值下的稳态—响应—一致性对比 |

三个工作包共享数据规范，但算法结论相互独立。WP1 不能用时间平滑掩盖串扰；WP3 不能用空间删点代替力值标定。

## 2. WP1：膜片算法价值重评

### 2.1 当前算法还有没有价值

**有价值，但价值需要重新定位。**

现有 SpatioTemporal 的有效部分是：利用膜片零背景、空间连通性和时间持续性，把受压主体与低值外围响应分开。它可以继续作为：

- 离线数据清理的对照基线。
- 接触区域检测或热图显示清理的候选方法。
- 测试串扰补偿算法是否优于简单门控的基准。

它不适合继续被称为“真实力值恢复算法”，原因是：

1. 当前空间掩膜使用整段最大值，包含未来信息，不能在线部署。
2. 串扰是受力导致的确定性或半确定性响应，可能持续存在；“持续时间长”不能证明它是真实接触。
3. 二元门控只能删除或保留，不能估计串扰贡献了多少 ADC。
4. 删除边缘小值可能使热图更干净，同时降低总 ADC、接触面积或真实边缘力值。

### 2.2 优化方向需要怎样修改

原优化方向是“更准确地判断小值是不是噪声”。beta3 应改成两级目标：

#### 目标 A：接触显示与事件检测

如果产品只要求热图边缘干净、接触区域稳定，可以研究轻量因果方法：

- 当前帧连通域与相对峰值阈值。
- 带进入/退出迟滞的接触状态机。
- 小连通域去除或形态学重建。
- 3×3 空间中值作为对照，但必须检查边界侵蚀和总响应变化。

这类方法输出的是“显示/接触掩膜”，不应直接宣称恢复了真实力分布。

#### 目标 B：真实力分布恢复

如果目标是尽量还原真实力，需要从门控转向串扰补偿模型。首轮模型可写为：

```text
y = A x + b + e
```

- `x`：真实接触响应或真实力分布。
- `y`：膜片观测到的 ADC 分布。
- `A`：通道自身响应和向邻域泄漏的串扰矩阵/空间核。
- `b`：零背景；膜片当前可取 0，但仍保留模型位置。
- `e`：剩余测量误差。

候选求解顺序：

1. **局部串扰系数校正**：用单点加载估计中心到邻域的比例，计算量小，最适合先验证。
2. **非负正则化反卷积**：串扰近似平移不变时使用空间核，并约束恢复值非负。
3. **稀疏/平滑约束逆问题**：串扰随位置变化时使用分区或位置相关矩阵，但需要更多标定数据。
4. **数据驱动回归**：只有在积累多设备同步真值后再考虑，当前不优先。

### 2.3 beta3 对现有 SpatioTemporal 的处理决定

| 组成 | 决定 | 理由 |
|---|---|---|
| 零背景前提 | 保留 | 与当前硬件认知一致 |
| 整段最大值掩膜 | 仅保留为离线对照 | 使用未来信息且记住特定接触位置 |
| 3×3 closing | 降为候选 | 可能填洞，也可能扩大支持域 |
| 逐像素泄漏计数器 | 改作事件/显示迟滞候选 | 对持续串扰没有识别能力，且损失启动帧 |
| 二元输出门控 | 不用于真实力恢复 | 无法估计串扰幅值或守恒总力 |
| 原算法整体 | 保留 benchmark | 用于判断新方法是否真正改进 |

### 2.4 WP1 后续阶段

1. stage1：记录嵌入式原样上报事实，并进一步确认采集极性、ADC 位宽和饱和范围。
2. stage2：采集单点/局部点载荷串扰响应，分析是否近似平移不变、线性和载荷无关。
3. stage3：比较原 SpatioTemporal、空间中值、连通域门控、局部系数校正和非负反卷积。
4. stage4：在位置留出、载荷留出和设备留出数据上验收。

## 3. WP2：beta2 补充数据方案复核

### 3.1 总体判断

**beta2 stage2 的补充采集仍然有用，但不能原样全部执行。**

- 对手套和织物垫，大部分实验继续有效，而且“bias 来自采集原理”的新认知使长期背景、重复上电和环境变化数据更重要。
- 对膜片，背景白噪声研究应降为低优先级；位置、载荷、面积和动态接触仍有用，但必须新增专门的串扰响应实验。
- 对力值稳定，砝码可以作为稳态弱真值，但不足以证明瞬时真实力；评价目标调整为减少长期跳动并保持载荷档位关系。

### 3.2 手套和织物垫：保留并增强

| beta2 实验 | beta3 决定 | 修改内容 |
|---|---|---|
| 长期纯背景 | 保留 | 增加重复上电、不同采集器、温度、供电和上传频率对比 |
| 完整压力周期 | 保留 | 使用已知砝码，并记录 bias 是否在加载后恢复 |
| 低 SNR 阶梯 | 保留 | 先扣除逐通道 bias，再按残差 SNR 分级，不按绝对 ADC 分级 |
| 固定压力长保持 | 保留 | 同时研究蠕变、bias 漂移和滤波器误吞稳态力 |
| 短时接触 | 降为可选 | 当前产品不要求快速接触，不作为主要验收项 |
| 多位置实验 | 保留 | 用于判断 bias 是采集通道属性还是传感位置属性 |

新增四项采集器诊断：

1. 同一传感器重复上电 10 次，每次预热后录制 2–5 分钟空载，检查 bias 可重复性。
2. 同一传感器更换采集器或采集通道，判断 bias 跟随传感器还是跟随采集链路。
3. 在多个上传频率下录制空载，检查随机噪声带宽和方差是否随采样率变化。
4. 若硬件允许，同时导出零点处理前的有符号原始量和当前 ADC，确认负向响应是否被偏置、整流、截断或映射。

### 3.3 64×64 膜片：保留、降级与新增

| beta2 实验 | beta3 决定 | 理由 |
|---|---|---|
| 长期空载背景 | 降为一次确认实验 | 已知零压力为 0，不再作为主要研究对象 |
| 完整加载周期 | 保留 | 需要加载/释放边界和动态响应 |
| 位置网格 | 保留并升级 | 是估计位置相关串扰的核心数据 |
| 低幅压力阶梯 | 保留 | 检查串扰比例是否随载荷变化 |
| 短接触 | 取消主要验收 | 当前产品只要求长期稳定压力 |
| 移动接触 | 取消主要验收 | 当前产品不要求滑动轨迹 |
| 接触面积变化 | 保留 | 串扰可能随压力梯度和压头尺寸变化 |
| 多膜片/重装夹 | 保留 | 判断补偿参数能否复用 |

膜片新增的最关键实验是“局部加载串扰响应扫描”，并增加全局加载对照：

1. 使用尽可能小且尺寸已知的平头压头。
2. 在中心、边缘、角部和若干内部网格点垂直加载。
3. 每个位置使用低、中、高至少三档力，保持 10–20 秒。
4. 记录砝码质量，并保留完整 64×64 原始 ADC。
5. 测量中心响应、各距离邻域响应、方向差异、总 ADC 和重复性。
6. 检查邻域串扰与中心 ADC 的比例是否随位置、载荷、面积和设备改变。
7. 使用覆盖大部分有效区域的平整加载板放置砝码，记录全局加载下的总 ADC、空间均匀性和边缘响应。

只有该实验能回答串扰更接近固定比例、空间卷积核，还是位置/载荷相关的非线性响应，从而决定补偿算法复杂度。

### 3.4 力值稳定新增数据

在当前只有砝码弱真值的条件下，力值算法需要：

- 多档已知砝码：每档重复加载并保持，比较稳态均值、方差和单调性。
- 完整加载周期：空载、放置砝码、长期保持、移除和恢复。
- 升载和降载阶梯：使用相同砝码组合，检查迟滞和历史依赖。
- 固定力保持 5–30 分钟：用于测量蠕变和温漂。
- 膜片分别采集局部压头加载和大平板全局加载。
- 织物垫主要采集多个局部位置和接触面积。
- 多次重复、多日期、多设备：用于区分测量噪声与设备差异。

这些数据不能提供逐帧真实力曲线，因此算法结论限定为“在固定砝码下减少跳动并保持档位关系”，不能表述为恢复了真实瞬时力。

## 4. WP3：真实力值稳定算法横向调研

### 4.1 先区分“还原”和“平滑”

观测链路建议拆成：

```text
原始 ADC
→ 零点/bias 校正
→ 串扰或坏点校正
→ ADC 到力值的非线性/分段标定
→ 时间稳定化
→ 显示或业务输出
```

时间滤波只能降低随机跳动，不能自动修复错误的 bias、串扰矩阵、迟滞或标定曲线。如果 ADC→力值映射在某一段斜率很大，1 ADC 抖动会被放大为明显力值跳动，应先检查标定曲线斜率和标定点稳定性。

### 4.2 候选方法比较

| 方法 | 优点 | 主要问题 | beta3 定位 |
|---|---|---|---|
| 移动平均 | 极简单，能降低白噪声 | 固定窗口延迟明显，短峰被摊薄 | 基线对照 |
| 指数移动平均 EMA | 因果、低成本、易按截止频率配置 | 平滑与响应速度固定折中 | 必测基线，优先级高 |
| 一阶/二阶低通 IIR | 截止频率定义清楚，工程成熟 | 相位延迟；高阶可能超调 | 必测基线 |
| 3/5 点中值 | 对孤立尖峰有效，不被异常值拉动 | 对连续白噪声效果有限，阶跃附近可能变形 | 作为 EMA 前置去毛刺 |
| Savitzky–Golay | 离线时较好地保留峰形和斜率 | 对白噪声并非总是最优；居中窗非因果，在线有延迟 | 离线分析对照，不作为首选在线方案 |
| One Euro Filter | 静止时强平滑、快速变化时自动提高带宽 | 参数与导数噪声相关，需防止噪声触发“放宽” | 动态响应参考，当前优先级较低 |
| α–β 滤波 | 比卡尔曼简单，可跟踪力值和变化率 | 噪声变化时适应性有限 | 动态力值轻量候选 |
| 标准卡尔曼 | 可融合状态模型和测量噪声，能估计力值/变化率 | `Q/R` 错误会迟钝或追噪；高斯线性假设有限 | 重点候选，但不是默认答案 |
| 自适应/鲁棒卡尔曼 | 可按创新调整噪声，拒绝异常点 | 参数更多，验证和维护成本高 | 标准方法不足后再研究 |
| 粒子滤波/复杂学习模型 | 可处理强非线性和多模态 | 数据和算力成本高、难解释 | 当前不优先 |

### 4.3 卡尔曼滤波是否可以

**可以，但在当前长期稳态场景中，它只是平滑候选，不是必然优于简单低通的方案。**

一个可测试的二状态模型为：

```text
state = [force, force_rate]
measurement = calibrated_force + measurement_noise
```

卡尔曼滤波比固定低通多出的价值是：它可以根据“力值连续变化”的状态模型，在测量抖动时依赖预测，在载荷变化时根据创新修正。但当前没有同步逐帧真值，参数只能从空载和固定砝码的稳态方差、加载过程的合理稳定时间中估计，不能证明其瞬时估计绝对准确。必须合理设置：

- `R`：稳态测量噪声方差，可从固定载荷数据估计。
- `Q`：真实力变化的不确定性，决定滤波器是否允许快速跟踪。
- 初始状态与接触开始/结束时的重置策略。
- 异常点创新门限，避免单帧尖峰拉动估计。

不建议一开始就给 4096 个 Cell 使用复杂多维卡尔曼。首轮应分别测试：

1. 单 Cell 标定力值的标量或二状态卡尔曼。
2. 总力值的卡尔曼。
3. 接触区域内各 Cell 独立滤波后求和，与先求总力再滤波比较。

因为当前不要求快速动态，One Euro 的优势会减弱。首轮优先比较 EMA、一阶/二阶低通 IIR 和标量卡尔曼；如果 EMA 或 IIR 已达到同等稳态效果和加载稳定时间，卡尔曼没有必要增加复杂度。

### 4.4 单 Cell 稳定是否等于总力稳定

不完全等价。若总力定义为各 Cell 力值之和：

```text
F_total[t] = sum(F_cell_i[t])
```

单 Cell 随机噪声彼此独立时，求和会部分抵消，相对跳动可能比单 Cell 更小；若多个 Cell 受共同 bias、供电波动或串扰影响，误差会同向叠加，总力反而可能更不稳定。

此外，逐 Cell 非线性标定、零截断和不同滤波状态会改变求和结果。分别对每个 Cell 做强平滑，也可能让接触面积变化时出现不同步。因此 beta3 同时比较两条管线：

1. `逐 Cell 校正/标定/滤波 → 求和`。
2. `逐 Cell 校正/标定 → 求和 → 对总力滤波`。

推荐默认策略是：逐 Cell 只做必要的 bias、串扰和异常点校正，先得到总力，再对总力做主要时间平滑；同时保留单 Cell 稳定指标用于诊断。这通常比给每个 Cell 使用复杂卡尔曼更容易控制总力偏差和计算成本。

### 4.5 首轮推荐算法组合

按照由简单到复杂的顺序：

1. **原始标定力值**：无滤波基线。
2. **Median-3 + EMA**：先去单帧尖峰，再降低稳态抖动；实现简单、行为容易解释。
3. **一阶/二阶低通 IIR**：按截止频率比较稳态波动和加载稳定时间。
4. **标量或二状态卡尔曼**：使用固定载荷估计 `R`，检验是否优于 EMA/IIR。
5. **One Euro Filter**：降为动态响应参考，不作为长期稳态场景的首选。
6. **鲁棒/自适应卡尔曼**：仅在噪声随载荷明显变化、标准方法无法兼顾时进入下一轮。

首轮不推荐把频谱门控直接用于最终力值，因为它的窗口和重建会增加延迟，且 beta2 已发现低 SNR 峰值放大。它仍可作为织物 ADC 去 bias 后的噪声抑制对照。

### 4.6 评价方式

不能只比较“标准差最低”。建议为每种算法形成精度—稳定—响应三维结果：

| 类别 | 指标 |
|---|---|
| 稳态 | 平均偏差、RMSE、标准差、峰峰值、95% 误差区间 |
| 加载过程 | 加载后稳定时间、释放后恢复时间、超调 |
| 长期 | 5–30 分钟漂移、分段均值变化、蠕变趋势 |
| 物理 | 升降载迟滞、砝码档位单调性、局部/全局总力一致性 |
| 工程 | 单帧耗时、内存、启动状态、参数数量 |

最终应画出“稳态标准差或 RMSE—延迟”的 Pareto 曲线，而不是预先规定某一种算法胜出。

## 5. beta3 分阶段计划

### stage1：采集链路与数据模型确认

- 记录嵌入式如实上报、无数据修饰的已确认结论。
- 继续确认膜片和织物类的测量极性、偏置来源、ADC 位宽和饱和范围。
- 审计当前 ADC→力值分段线性标定的斜率、标定采样平均和可能的误差放大区间。
- 输出数据字典、观测模型和最终采集表。

**进入条件**：能够明确每类设备的 `raw ADC → uploaded ADC → calibrated force` 链路。

### stage2：数据采集与现象辨识

- 织物类完成 bias 重复性、随机噪声和完整加载周期采集。
- 膜片完成点载荷串扰响应扫描。
- 力值研究完成多档砝码、升降载阶梯和长保持数据。
- 判断串扰是否近似线性/平移不变，噪声是否近似稳态，标定是否存在明显迟滞和蠕变。

**进入条件**：数据足以区分固定偏置、随机噪声、串扰、迟滞和长期漂移，并能比较砝码档位的稳态一致性。

### stage3：候选算法离线横评

- WP1 比较显示门控与串扰补偿方法。
- WP3 比较无滤波、EMA、IIR、Median+EMA、One Euro 和卡尔曼，并分别测试“逐 Cell 后求和”与“先求总力后滤波”。
- 使用完整录制留出、位置留出和设备留出测试。
- 生成 CSV 指标、对比图和失败路线说明。

**进入条件**：至少一个方法在可接受稳定时间下优于简单 EMA，并且不破坏砝码档位单调性、总力均值和局部/全局一致性。

### stage4：因果性与产品化前验收

- 将胜出算法改为严格流式状态机。
- 测试启动、重置、掉帧、采样率变化和长时间运行。
- 测量单帧耗时、内存和端到端延迟。
- 形成是否值得进入主项目的结论，不在 v1.0.10 内修改主程序。

## 6. 当前初步决策

1. **膜片算法保留，但降级为 benchmark 和显示/区域检测候选。**真实力恢复方向转向有标定数据支持的串扰补偿。
2. **beta2 补充数据方案仍有用，但需要按设备重排优先级。**织物类加强 bias 诊断；膜片减少背景研究，新增局部串扰扫描和全局加载对照；力值研究改用多档砝码稳态弱真值。
3. **卡尔曼可以测试，但不预设胜出。**首轮与 Median+EMA、低通 IIR 在相近加载稳定时间下横向比较，One Euro 仅作动态参考。
4. **处理顺序必须先校正物理误差，再做时间稳定。**平滑算法不能替代 bias、串扰、迟滞和标定问题。
5. **总力是主输出，单 Cell 是基础诊断量。**优先验证先求总力再滤波，同时保留逐 Cell 轻量校正管线作为对照。

## 7. 已确认条件与剩余信息

已确认：

1. 不要求快速敲击和滑动，只要求长期稳定压力。
2. 当前只有砝码加载弱真值，没有同步高精度力值时间序列。
3. 嵌入式如实上报传感器数据，不做修饰。
4. 总力稳定优先，单 Cell 稳定用于构建与诊断。

进入数据采集前仍建议补充：

1. 膜片“全局压力”使用的加载板尺寸、刚度和砝码放置方式。
2. 每类设备预计使用的砝码档位和单次保持时长。
3. 当前总力是“各 Cell 标定力直接求和”，还是嵌入式/上位机另有合力公式。
