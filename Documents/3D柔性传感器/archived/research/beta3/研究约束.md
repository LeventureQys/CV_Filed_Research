# beta3 研究约束

> 版本性质：研究计划与算法验证，不修改 TactileSense 主项目代码  
> 当前阶段：问题重定义与方案调研，用户确认前不进入算法实现

## 1. 研究范围

1. 所有 beta3 文档、脚本、派生数据、指标和图片只能位于 `v1.0.10 - research/beta3/`。
2. beta3 将三个问题分开研究，不再用“降噪”一个词混合描述：
   - 64×64 膜片受压边缘的空间串扰。
   - 手套和织物垫由采集原理产生的零点偏置及随机噪声。
   - ADC 标定为力值后的显示跳动与真实力值估计。
3. 不修改嵌入式固件、上位机主程序或现有标定流程；如发现采集链路信息不足，只形成接口与数据需求。
4. beta3 可以研究力值标定与稳定化，作为对 beta2“仅研究 ADC”的明确扩展，但当前只有砝码质量弱真值，不声称恢复瞬时真实力。

## 2. 物理认知

1. 64×64 膜片零压力背景为 0 是当前已知事实，不再假设其存在需要频谱抑制的白噪声。
2. 膜片受压区域外围的微弱值按“串扰候选”研究，而不是默认视为随机白噪声。
3. 手套和织物垫的背景偏置可能来自采集器与传感原理；必须区分：
   - 可重复的固定偏置。
   - 随温度、时间、供电或设备变化的慢漂移。
   - 围绕偏置的随机噪声。
4. “曲线更平滑”不等于“真实力值更准确”；去偏置、串扰补偿、ADC→力值标定和时间滤波必须分别评估。
5. 嵌入式将传感器数据如实上报，不做平滑、扣基线或其他数据修饰；beta3 将当前 CSV 视为原始 ADC 观测。
6. 当前只能使用已知砝码作为弱真值，研究结论限定为定性降噪、稳态重复性和相对一致性。

## 3. 产品场景约束

1. 不要求快速敲击和滑动，只研究长期稳定受压。
2. 织物垫主要研究局部压力。
3. 64×64 膜片同时研究局部压力和全局压力。
4. 输出优先级为总力稳定，其次是单 Cell 和空间分布稳定。
5. 单 Cell 稳定是重要基础，但必须独立评价总力；共同偏置、串扰、非线性标定和逐 Cell 截断可能在求和后累积。

## 4. 算法约束

1. 禁止使用待处理整段录制的未来帧构建在线空间掩膜。
2. 膜片串扰算法必须检查总力、峰值、接触面积、质心和边缘形状，不能只凭热图更干净判定有效。
3. 织物类算法必须先估计并扣除偏置，再评估随机噪声；不得把固定 bias 当作白噪声直接频谱抑制。
4. 时间平滑算法必须是因果版本，参数以秒、截止频率或统计量定义，不以固定帧数跨采样率复用。
5. 卡尔曼滤波必须明确状态、观测、过程噪声和测量噪声的物理含义；不得只靠调参使图片变平。
6. 空间滤波不得无依据地把邻域 ADC 平均为新的力值；若使用空间补偿，必须有点载荷串扰响应或其他可验证模型。
7. 所有算法必须保留“无处理”基线，并与简单方法比较，复杂算法只有在精度—延迟权衡上显著更好时才继续。

## 5. 数据约束

1. 每条动态数据必须包含背景、加载、保持、释放和恢复，并有事件时刻。
2. 力值研究以砝码质量为稳态弱真值，只能比较稳态均值、重复性、跳动和不同砝码间的单调关系。
3. 膜片串扰研究必须包含已知位置、已知压头尺寸和已知载荷的点载荷/局部载荷扫描。
4. 标定数据必须包含升载与降载，用于识别迟滞；包含长时间保持，用于识别蠕变。
5. 训练、参数选择和最终测试按完整录制划分，至少保留位置留出和设备留出测试。
6. 当前嵌入式不修饰传感器数据；若后续固件行为发生变化，必须记录处理规则并保留可比的原始数据。

## 6. 指标约束

### 6.1 串扰补偿

- 非接触区域残余值与误激活面积。
- 接触区域 ADC/力值保持率。
- 总响应保持率。
- 峰值误差、质心偏移、接触面积误差和空间 IoU。
- 新位置、新载荷、新压头和新设备上的泛化误差。

### 6.2 力值稳定

- 稳态偏差、RMSE、标准差和峰峰值。
- 加载后稳定时间、释放后恢复时间和超调。
- 升载/降载迟滞误差和长时间蠕变误差。
- 砝码质量与稳态估计总力之间的单调性、重复性和相对误差。
- 局部与全局加载下的总力一致性。

## 7. 结果管理

1. beta3 每个工作包先形成假设、数据需求、候选算法和否决条件，再进入代码实验。
2. 每轮实验保留可重复脚本、机器可读指标和处理前后对比图。
3. 失败路线记录失败原因，不因视觉效果好而继续保留。
4. 用户确认本轮计划后，才创建具体 stage 的算法实现和实验结果。
