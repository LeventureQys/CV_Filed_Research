# beta2 stage1 验收说明

## 验收结果

| 项目 | 结果 | 证据 |
|---|---|---|
| 仅修改研究版本目录 | 通过 | 新增内容全部位于 beta2 与研究总览内 |
| 同时覆盖手套和织物垫 | 通过 | 两类真实背景、模拟数据和压力录制均已运行 |
| 每类至少五种模拟工况 | 通过 | 持续、渐变、短时、重叠、低 SNR 共五类 |
| 不依赖二维邻接 | 通过 | 算法输入仅为时间帧与通道维度 |
| 通道重排不变性 | 通过 | 任意重排后恢复原顺序，输出数值一致 |
| 常规场景 SRR 0.90 至 1.10 | 通过 | 十组结果均为 0.901 至 1.035 |
| 所有场景峰值保持 0.90 至 1.15 | 失败 | 低 SNR 手套为 1.305，织物垫为 1.575 |
| 真实数据包含对比图 | 通过 | 手套与织物垫均生成时序曲线和矩阵前后热力图 |
| 单元测试 | 通过 | 3 项测试通过 |

## 判定

stage1 作为路线可行性验证通过，但算法成品验收不通过。阻塞项是低 SNR 伪峰放大，必须在下一 stage 解决后才能进入在线产品化评估。
