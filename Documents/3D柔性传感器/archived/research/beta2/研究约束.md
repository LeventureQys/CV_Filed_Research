# beta2 研究约束

## 1. 研究范围

1. 所有研究代码、数据派生物、图片和记录只能位于当前研究版本目录内。
2. beta2 只研究 ADC 数据降噪，不修改主程序，不讨论力值标定。
3. 碳膜与织物类传感器采用不同路线，不再强求一个算法覆盖所有设备。
4. 碳膜路线保留已验证的时空筛选方案作为对照，beta2 的主要对象是手套和织物垫。

## 2. 算法约束

1. 织物类算法不得依赖通道编号等同于二维物理邻接关系。
2. 可以利用单通道时间连续性、背景噪声统计、采样率和全通道共享统计量。
3. 背景分析与数据处理必须分离，背景模型不得使用待评估压力段的未来真值。
4. 不得只用硬阈值删除低幅值数据，必须检查低 SNR 真信号是否被误删。
5. 算法参数必须按秒或统计量定义，不能把固定帧数直接套用到不同采样率设备。
6. 输出不得整体压缩有效压力能量，也不得通过放大残余噪声获得表面上的高保持率。

## 3. 数据约束

1. 新路线先通过模拟数据，再进入真实录制数据。
2. 每轮模拟评估至少包含五种工况，覆盖持续接触、渐变接触、短接触、重叠接触和低 SNR 接触。
3. 模拟噪声优先从真实背景录制中重采样，不以理想高斯噪声代替全部硬件噪声。
4. 织物类研究必须同时覆盖手套和织物垫。
5. 若算法声称与空间排列无关，必须增加通道重排不变性验证。
6. 真实压力录制没有干净真值，不能把视觉平滑或相对原始数据保持率当作最终正确性证明。

## 4. 指标约束

1. 模拟数据至少报告 RMSE、背景噪声抑制比、信号保持率和峰值保持率。
2. 背景区与压力区必须分开计算，禁止只报告全局平均指标。
3. 信号保持率目标区间为 0.90 至 1.10，超出区间需要解释衰减或放大原因。
4. 峰值保持率目标区间为 0.90 至 1.15，低 SNR 场景同样适用。
5. 真实数据至少报告背景抑制、压力能量相对保持和压力峰值相对保持，并明确这些是无真值代理指标。
6. 进入在线实现前必须补充处理延迟、实时因子和启动瞬态指标。

## 5. 结果管理

1. 每个 stage 保留一条活跃算法路线，失败路线应说明失败原因后归档。
2. 每轮必须保留可重复运行的脚本、机器可读指标和模拟/真实对比图。
3. 最新算法总览必须同时展示手套、织物垫和碳膜的当前结论。
4. 任何“可用”结论必须同时满足模拟定量结果和真实数据合理性检查。
