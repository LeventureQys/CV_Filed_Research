# TactileSense v1.0.10 降噪算法研究总结

> 研究日期：2026-07-10 至 2026-07-11  
> 当前进度：beta2 stage2  
> 版本性质：离线算法研究，不修改 TactileSense 主程序

## 1. 研究目标

本目录用于研究多阵列触觉传感器原始 ADC 数据的降噪方法。研究覆盖三类设备：

| 设备 | 传感器类型 | 数据规模 | 主要噪声特征 |
|---|---|---:|---|
| 手套 | 织物柔性传感器 | 96 通道，约 20 Hz | 无压力时仍有逐通道随机小幅跳动 |
| 织物垫 | 织物柔性传感器 | 12×8，约 10 Hz | 通道基线差异明显，存在持续白噪声 |
| 64×64 膜片 | 碳膜柔性传感器 | 4096 通道，约 50–60 Hz | 静默背景较干净，受力团块边缘存在低值毛刺和孤立值 |

研究仅处理 ADC 数据，不涉及力值标定。所有代码、数据派生物和实验结果均保留在本目录中。

## 2. 核心结论

三类设备不能共用一个统一降噪器。碳膜噪声具有可利用的空间结构，而手套和织物垫的通道编号不一定对应真实物理邻接，适合采用逐通道时间序列方法。

| 设备 | 当前推荐路线 | 验证状态 | 结论 |
|---|---|---|---|
| 64×64 膜片 | SpatioTemporal 时空门控 | 固定接触离线基线成立，产品验收未通过 | 自身录制掩膜下改动较小，但使用未来信息，跨位置、短接触、移动接触和低压力均存在漏检风险 |
| 手套 | TemporalSpectralGate 时域谱门控 | 路线验证通过，成品验收未通过 | 常规压力保持良好，但低 SNR 场景存在伪峰放大 |
| 织物垫 | TemporalSpectralGate 时域谱门控 | 路线验证通过，成品验收未通过 | 高 SNR 压力几乎无损，背景得到中等抑制，但低 SNR 伪峰更明显 |

当前结果不能直接作为产品算法集成。尤其是 beta2 的谱门控仍是离线、非因果实现，且尚未满足全部峰值保持指标。

## 3. 研究迭代

### 3.1 beta1 stage1：统计门限原型

第一阶段建立了 `Analyzer + Processor` 框架，以纯背景数据估计逐通道基线和噪声统计，再通过统计门限输出非负残差。同时提供 CSV 加载、动画回放、批量 Benchmark 和单文件统计 GUI。

该方案验证了研究工具链，但统一统计门限会造成明显信号失真，不能覆盖三类设备。

### 3.2 beta1 stage2：按设备拆分路线

这一阶段测试了空间滤波、EdgeGate、TemporalGate、SpatioTemporal、Wiener、SVD、PCA、NMF 等路线，并用合成压力团块和真实录制数据检查信号保持与背景抑制。

最终为 64×64 膜片保留 SpatioTemporal：

1. 使用全时段最大值识别可能的压力团块区域，并进行形态学闭运算。
2. 使用带衰减的连续计数器确认通道是否具有时序持续性。
3. 仅保留同时通过空间与时序判据的原始 ADC 值。

beta2 stage2 复核后，以上结论只能视为特定样本上的初步观察。七条压力录制的自身离线掩膜总值保持率为 0.9714–0.9980，其中一条 500g 录制的 `>=100 ADC` 高值保持率仅 0.9733，不支持“高值无丢失”的强结论。空间掩膜还使用整段未来数据；跨录制应用时，非同录制组合平均仅保留 0.2323 的 ADC 总值，多组完全归零。

手套和织物垫在这一阶段仍未解决。逐通道硬门限、空间团块和低秩重建均会产生过度删除、压缩或结构假设不成立的问题。

### 3.3 beta2 stage1：音频式背景谱学习

beta2 针对手套和织物垫引入 TemporalSpectralGate。该算法不读取二维坐标，只使用各通道的时间序列、纯背景录制和采样率：

1. 以逐通道背景中位数估计稳定基线。
2. 使用 1.6 秒 Hann 窗和 75% 重叠执行 STFT，窗长按采样率换算。
3. 以背景频谱功率的时间中位数估计逐通道噪声功率谱。
4. 使用软 Wiener 型增益抑制接近背景噪声谱的成分。
5. 通过 ISTFT 重建，并将负残差截断为零。

该路线借鉴音频降噪的噪声谱学习方法，但不假设触觉信号与音频具有相同性质。通道重排测试通过，证明实现不依赖二维物理邻接。

### 3.4 beta2 stage2：64×64 膜片合理性复核

本阶段独立复现 SpatioTemporal，补充了七条真实压力录制的离线/前缀因果对比、阈值扫描、跨录制掩膜测试及合成反例。结果表明该算法适合作为固定位置稳定接触的离线清理基线，但整段最大值空间掩膜属于 oracle；旧位置掩膜无法泛化到新位置，1–2 帧接触、快速移动接触和低于空间阈值的接触会完全丢失。

完整证据、限制和实物采集建议见 `beta2/stage2/64x64膜片算法与真实数据合理性评估.md`。

## 4. beta2 量化结果

### 4.1 模拟数据

模拟噪声由真实背景残差重采样得到，并分别覆盖持续接触、渐变接触、短接触、重叠接触和低 SNR 接触。

| 设备 | 常规场景 SRR | 背景噪声抑制 BNSR | 低 SNR 峰值保持 | 判定 |
|---|---:|---:|---:|---|
| 手套 | 0.955–1.005 | 7.00–7.18 dB | 1.305 | 超过 1.15 上限 |
| 织物垫 | 1.011–1.035 | 4.60–4.93 dB | 1.575 | 超过 1.15 上限 |

常规场景的压力能量保持良好。低 SNR 场景虽然总能量接近真值，但残余随机成分会形成瞬时伪峰，因此不能只根据 SRR 判断算法可用。

### 4.2 真实录制

| 设备 | 背景抑制 | 压力能量相对保持 | 压力峰值相对保持 |
|---|---:|---:|---:|
| 手套 | 4.18 dB | 0.994 | 0.960 |
| 织物垫 | 3.12 dB | 1.000 | 1.000 |

真实压力录制没有同步干净真值。这些结果只能说明主要压力曲线相对原始数据没有明显衰减，并不能证明所有低幅值均被正确分类。

## 5. 验收状态

beta2 stage1 作为路线可行性验证通过，但算法成品验收不通过。

已通过：

- 同时覆盖手套和织物垫，并为每类设备构造五种模拟工况。
- 使用真实背景噪声，分别计算背景区和压力区指标。
- 常规场景信号保持率位于目标区间。
- 通道重排前后结果一致，不依赖二维邻接。
- 已生成模拟、真实时序和矩阵热力图，并保留机器可读指标。
- TemporalSpectralGate 的 3 项单元测试通过。

未通过：

- 低 SNR 场景峰值保持率超过 0.90–1.15 的验收范围。
- 当前谱门控使用整段数据和重叠分帧，不是可直接接入实时采集链路的因果算法。
- 尚未评估在线处理延迟、实时因子、启动瞬态和持续运行状态管理。

## 7. 环境与复现

建议使用 Python 3.10 或更高版本。核心依赖为：

```powershell
python -m pip install numpy scipy matplotlib
```

运行 beta2 stage1 全量实验，重新生成 CSV 指标和对比图：

```powershell
python "Document\Update\v1.0.10 - research\beta2\stage1\scripts\run_stage1.py"
```

运行 TemporalSpectralGate 单元测试：

```powershell
python "Document\Update\v1.0.10 - research\beta2\stage1\tests\test_temporal_spectral_gate.py"
```

运行 64×64 膜片复核实验：

```powershell
python "Document\Update\v1.0.10 - research\beta2\stage2\tests\test_membrane_spatiotemporal.py"
python "Document\Update\v1.0.10 - research\beta2\stage2\scripts\evaluate_membrane.py"
python "Document\Update\v1.0.10 - research\beta2\stage2\scripts\evaluate_counterexamples.py"
```

启动 beta1 研究 GUI：

```powershell
python "Document\Update\v1.0.10 - research\src\main.py"
```

GUI 使用 Tkinter；部分可视化需要可用的桌面图形环境。历史归档中的 NMF 路线还使用 `scikit-learn`，但复现当前 beta2 结论不需要该依赖。

## 9. 后续建议

1. 优先解决低 SNR 伪峰，尝试跨时间/频率增益平滑、峰值置信约束或 decision-directed 先验 SNR，而不是继续提高硬门限。
2. 将谱门控改造成流式因果实现，明确背景学习期、窗口缓存、算法延迟和状态重置行为。
3. 增加在线指标，包括端到端延迟、单帧耗时、实时因子和启动瞬态。
4. 补充带同步真值或可控载荷的低幅压力数据，避免仅用原始录制保持率替代正确性证明。
5. 产品化时按设备类型选择算法，不再尝试用统一参数覆盖碳膜和织物类传感器。
6. 膜片算法取消整段最大值 oracle 掩膜，使用位置留出、设备留出和同步力值/位置真值验证因果版本。
