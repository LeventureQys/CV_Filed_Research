# beta4 设计文档

> 日期：2026-07-14  
> 版本性质：织物垫实物数据研究，不修改 TactileSense 主项目代码  
> 前置阶段：beta3 仿真研究已完成，已获得织物垫补充实物数据

## 1. 背景与目标

beta3 在合成数据上完成了算法筛选，并在三类传感器（织物垫、手套、膜片）的早期录制上做了初步真实数据验证。目前已按照 beta3《下一步实物数据采集与整理要求》采集了织物垫的补充实物数据，包含背景噪声、500 g/1 kg/1.5 kg 砝码压力、空载+加载+恢复循环、1 kg 长时保持（20 min）和空载 20 min。

beta4 的目标：在织物垫实物数据上，复测 beta3 全部时间滤波算法，并新增三种有明确物理意义的候选算法（自适应基线估计、双状态卡尔曼、鲁棒 EMA），最终给出完整的算法比对表，精炼至 3-4 组最佳方案，明确推荐优先级和放弃理由。

## 3. 完整接口契约

### 3.1 数据加载

新增 `scripts/data_loader_v2.py`，统一加载两种格式：

```
load_recording(csv_path: str, format: str) -> tuple[np.ndarray, dict]
```

- `format="old"`：委托 `src/alg/data_loader.load_csv`
- `format="new"`：解析新格式 header，提取 elapsed 列作为时间轴，ch0..ch95 为数据列
- 返回：`(frames, meta)`，其中 `meta` 包含 `sample_freq_hz`、`n_frames`、`channels`、`path`、`device_label`

确定采样率规则：
- 旧格式：优先读取 `录制频率` header；为 "raw" 时从时间戳估算
- 新格式：读取 `record_frequency` header；若为 0 则从 elapsed 列估算

### 3.2 新增算法

以下三者实现在 `scripts/filters.py`（追加到 beta3 原有 filters 之后）：

#### 3.2.1 自适应基线（Adaptive Baseline）

```
adaptive_baseline(cells: np.ndarray, sample_rate: float, window_s: float = 10.0) -> np.ndarray
```

物理含义：对每个 Cell，用过去 `window_s` 秒的窗口内分位数值作为实时基线估计。窗口内取中位数（稳健），当前帧减去该基线后截断为非负值。

参数：
- `window_s`：滑动窗口时长（秒），默认 10 s
- 分位数：0.5（中位数）

输入：原始逐 Cell ADC，shape (N, C)
输出：自适应基线校正后的逐 Cell ADC，shape (N, C)

#### 3.2.2 双状态卡尔曼（Dual-State Kalman）

```
dual_state_kalman(values: np.ndarray, sample_rate: float,
                  process_noise_force: float = 0.01,
                  process_noise_drift: float = 1e-4,
                  measurement_noise: float = 1.0) -> np.ndarray
```

状态向量：`[总力, 漂移]^T`
观测：当前总力（单变量标量）

状态转移：
```
F = [[1, dt],
     [0, 1]]
```

观测矩阵：
```
H = [1, 0]
```

物理含义：
- 状态 1：真实总力，受随机游走驱动（`process_noise_force`）
- 状态 2：慢漂移，变化更缓慢（`process_noise_drift` << `process_noise_force`）
- 观测：扣除基线后的总 ADC（已完成 bias 校正）

参数默认为 beta3 稳态型卡尔曼对应值的近似替代；实物数据上按固定砝码稳态段验证后手动调整。

输入：总力序列，shape (N,)
输出：滤波后总力序列，shape (N,)

#### 3.2.3 鲁棒 EMA（Huber Weighted EMA）

```
huber_ema(values: np.ndarray, sample_rate: float,
          time_constant: float = 0.8,
          threshold_sigma: float = 3.0) -> np.ndarray
```

物理含义：标准一阶 EMA，但在更新步使用 Huber 损失函数自动抑制离群值。当 `|z[k] - x[k-1]|` 超过 `threshold_sigma * sigma_est` 时，将残差缩放为 `sign(residual) * threshold_sigma * sigma_est`。

参数：
- `time_constant`：EMA 时间常数（秒），默认 0.8 s
- `threshold_sigma`：截断倍数，默认 3.0 Sigma
- `sigma_est`：在线估计值，取 EMA 残差的 MAD（中位数绝对偏差）

输入：总力序列，shape (N,)
输出：滤波后总力序列，shape (N,)

### 3.3 分析管线

```
数据加载
  ├─ 旧格式 5 条 → load_csv
  └─ 新格式 5 条 → load_recording_v2

对每条录制：
  1. 背景扣除（使用独立背景录制的中位数）
  2. 运行 12 组算法（原始 + 8 个 beta3 + 3 个新增）
  3. 计算指标：稳态均值、标准差、峰峰值、RMSE（归一化）、一阶差分标准差（roughness）、粗糙度保持率
  4. 对有空载+加载+释放分段的录制，额外计算稳定时间（接近稳定段进入 ±2% 阈值的时刻）

汇总指标写入 CSV，生成全算法比对图 → 比选精炼 → 最终 3-4 组比对图
```

### 3.4 验收标准

1. 所有 10 条织物垫录制（旧格式 5 条 + 新格式 5 条）正确加载、背景扣除、算法运行无异常。
2. 输出机器可读指标文件（CSV）。
3. 输出全算法比对图（所有 12 组）和精炼比对图（3-4 组最终推荐）。
4. 研究报告包含：数据描述、算法列表与说明、指标表格、各重量档位候选算法比对、最终推荐与放弃算法理由。
