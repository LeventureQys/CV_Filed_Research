> 验收环境：Windows + PowerShell + Python 3.14 + NumPy/SciPy/Matplotlib

## 1. 验收范围

- 覆盖：所有 beta4 新增脚本（data_loader_v2.py, filters.py, run_beta4.py），输出指标 CSV，比对图，研究报告

## 2. 前置条件

- 仓库位于 `multi-device-cascade-host-cpp` 根目录
- Python 3.14，已安装 numpy, scipy, matplotlib
- 织物垫补充数据已位于 `DataSet/织物垫/`

## 4. 证据要求

- 运行输出日志保存为文本文件
- 所有 PNG 图保存为文件
- CSV 指标保存为文件
- 报告本身即为交付物

## 5. 失败处理

- 编译/导入失败 → 退回修复脚本语法或导入路径
- 运行异常 → 检查数据路径、采样率估算、算法数值稳定性
- 指标或图表缺失 → 补充代码
- 报告不完整 → 补充章节

## 6. 回归范围

- beta3 已有数据和脚本不受影响（禁止修改 beta3/ 目录）
- 本验收不影响主项目
