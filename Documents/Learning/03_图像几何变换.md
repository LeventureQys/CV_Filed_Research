# 图像几何变换：旋转、缩放与插值的艺术

> 从"挪动像素"到图像重建

## 写在前面

前面两章说了图像的"诞生"（采样量化）和"像素级操作"（点运算与代数运算）。这两类操作有一个共同特点：**像素的位置没变**，变的只是值。

这一章完全不同。我们要讨论的是**改变像素的位置**，也就是几何变换。

想象一下：你把照片旋转了 30 度，放大到 2 倍，或者压缩成一张小缩略图——这些都在做几何变换。看似简单，但里面藏着一个深刻的矛盾：

- 我们想得到**新位置**上的像素值
- 但原始图像只记录了**旧位置**上的像素值
- 新位置往往落在旧像素之间——所以需要**插值**

从 DSP 的角度看，这和"对离散信号做重采样"是同一件事，只不过变成了二维的。如果你熟悉变采样率转换（resampling）里面的插值和抗混叠滤波，你会觉得很多概念似曾相识。

好，我们分三步走：先讲**仿射变换**这个几何骨架，再讲**插值放大**怎么填像素，最后讲**缩小**怎么做才不 alias。

## 1. 仿射变换

### 1.1 齐次坐标系

先想一个简单问题：想把一张图平移 $(t_x, t_y)$，怎么用矩阵写？

在 2D 坐标里平移是加法，旋转和缩放是乘法。如果能统一成乘法，那组合变换就只需要**连乘矩阵**，优雅又高效。这就是**齐次坐标系**（homogeneous coordinates）的动机。

把一个二维点 $(x, y)$ 扩展成三维 $(x, y, 1)$——末尾加一个 1，未来如果出现投影透视，那个 1 也可以变成别的值 $w$，通过除以 $w$ 回到 2D。

$$
\\begin{pmatrix} x \\\\ y \\\\ 1 \\end{pmatrix}
$$

在齐次坐标系下，所有基本变换统一成了 $3 \\times 3$ 矩阵乘法：

| 变换 | 齐次矩阵 | 效果 |
|:---|:---|:---|
| 平移 $(t_x, t_y)$ | $\\begin{pmatrix}1 & 0 & t_x \\\\ 0 & 1 & t_y \\\\ 0 & 0 & 1\\end{pmatrix}$ | 移动位置 |
| 缩放 $(s_x, s_y)$ | $\\begin{pmatrix}s_x & 0 & 0 \\\\ 0 & s_y & 0 \\\\ 0 & 0 & 1\\end{pmatrix}$ | 放大/缩小 |
| 旋转 $\\theta$ | $\\begin{pmatrix}\\cos\\theta & -\\sin\\theta & 0 \\\\ \\sin\\theta & \\cos\\theta & 0 \\\\ 0 & 0 & 1\\end{pmatrix}$ | 绕原点旋转 |
| 错切（X方向 $s$） | $\\begin{pmatrix}1 & s & 0 \\\\ 0 & 1 & 0 \\\\ 0 & 0 & 1\\end{pmatrix}$ | 斜拉 |

**组合变换**就是把矩阵乘起来。先旋转再平移，对应：

$$
\\mathbf{p}' = \\mathbf{T} \\cdot \\mathbf{R} \\cdot \\mathbf{p}
$$

注意顺序：**矩阵乘法从右往左作用**，所以 $\\mathbf{T}$ 的平移作用在旋转之后的结果上。

> 💡 **齐次坐标系的优雅之处**：没有它，你要把平移写成加法，旋转缩写成乘法，组合变换就变成 $x' = R(s \\cdot x) + t$，没法写成单一的矩阵。有了齐次坐标，**一切线性变换加上平移，统一成一个矩阵乘法**——这在图形学、机器人学、SLAM 里都是基础工具。

### 1.2 图像仿射变换

图像原本定义在离散网格 $[0, W-1] \\times [0, H-1]$ 上。施加一个仿射变换，就是把每个输出位置 $(i', j')$ 映射回输入图上的某个浮点位置 $(x, y)$，然后取值。

完整形式是：

$$
\\begin{pmatrix} x \\\\ y \\\\ 1 \\end{pmatrix} = \\mathbf{M}^{-1} \\begin{pmatrix} i' \\\\ j' \\\\ 1 \\end{pmatrix}
$$

其中 $\\mathbf{M}$ 是前向变换矩阵（输出到输入的反向映射）。等等，为什么是反向映射？

#### 前向映射 vs 反向映射

直觉上你可能会想：遍历原图的每个像素 $(i, j)$，算它在新图里的位置 $(i', j')$，然后填过去。

这叫**前向映射**（forward mapping）。它有致命问题：

- 多个原像素可能映射到同一个新像素（重叠）
- 有些新像素可能**没有任何原像素落进来**（空洞）

```
前向映射的后果：
原图            映射后
┌──┬──┐        ┌────┬────┬────┐
│a │b │        │ a  │    │ b  │  ← 中间空洞
├──┼──┤        ├────┼────┼────┤
│c │d │   →    │ c  │  ░░│    │  ← ░░ 是重叠
└──┴──┘        ├────┼────┼────┤
               │ d  │    │    │
               └────┴────┴────┘
```

所以工程上几乎不用前向映射。标准做法是**反向映射**（backward mapping）：

对于输出图的每个像素位置 $(i', j')$，用**逆变换**算出它在原图中对应的位置 $(x, y)$：

$$
\\begin{pmatrix} x \\\\ y \\\\ 1 \\end{pmatrix} = \\mathbf{M}^{-1} \\begin{pmatrix} i' \\\\ j' \\\\ 1 \\end{pmatrix}
$$

然后从原图插值出该位置的值。这样输出图**每个像素都有值**，没有空洞，没有重叠。

```
反向映射（标准做法）：
输出图                     原图
┌──┬──┬──┐               ┌────┬────┐
│? │? │? │   (i',j')     │ a  │ b  │
├──┼──┼──┤   ───────►    ├────┼────┤
│? │? │? │    查逆变换     │ c  │ d  │
└──┴──┴──┘               └────┴────┘
                  找到浮点位置 (x,y) → 插值
```

### 1.3 仿射变换算法设计

完整算法的伪代码：

```
输入：原图 I_in (H_in × W_in)，仿射矩阵 M (3×3)
输出：输出图 I_out (H_out × W_out)

步骤：
1. 计算 M 的逆矩阵 M_inv
2. 对于输出图的每个像素位置 (i', j'):
   a. (x, y, w) = M_inv · (j', i', 1)    // 齐次坐标下的反向映射
   b. x /= w;  y /= w                     // 如果有透视分量，归一化
   c. 如果 (x, y) 在原图边界内
      - 从 I_in 在 (x, y) 处插值出值 v
      - I_out[i', j'] = v
      - 否则设为 0（或自定义的填充值）
```

**关于图像坐标的一点提醒**（和第一章呼应一下）：

- 数学上我们习惯 $(x, y)$，$x$ 是列方向，$y$ 是行方向
- 代码里你访问某个像素，往往是 `image[row, col]`，即 `image[y, x]`
- 所以当你写代码时，**输出图的循环用 $(i, j)$ 表示行和列**，映射到原图坐标时注意顺序不要搞反

一个更具体的 Python 示意（用 `numpy` 矩阵运算，不靠 OpenCV）：

```python
import numpy as np

def affine_transform(img, M, out_shape):
    """img: (H, W), M: 3x3 仿射矩阵"""
    H_in, W_in = img.shape
    H_out, W_out = out_shape
    M_inv = np.linalg.inv(M)

    # 生成输出网格坐标
    yy, xx = np.meshgrid(np.arange(H_out), np.arange(W_out), indexing='ij')
    ones = np.ones_like(xx)

    # 展平并转换为齐次坐标 (x, y, 1) 的列向量
    coords = np.stack([xx.ravel(), yy.ravel(), ones.ravel()], axis=0)  # 3 × N

    # 反向映射
    src = M_inv @ coords  # 3 × N
    src_x = src[0].reshape(H_out, W_out)
    src_y = src[1].reshape(H_out, W_out)
    src_w = src[2].reshape(H_out, W_out)

    # 如果有透视分量，归一化（标准仿射 w=1，这步是安全的通用处理）
    src_x = src_x / src_w
    src_y = src_y / src_w

    # 边界检查 + 最近邻插值（用 round 取整）
    # 实际工程中这里会换成双线性/双三次插值
    src_xi = np.round(src_x).astype(int)
    src_yi = np.round(src_y).astype(int)

    mask = (0 <= src_xi) & (src_xi < W_in) & (0 <= src_yi) & (src_yi < H_in)
    out = np.zeros((H_out, W_out), dtype=img.dtype)
    out[mask] = img[src_yi[mask], src_xi[mask]]
    return out
```

实际实现里可以一次算全图的坐标映射，**向量化**执行。核心就是上面这段逻辑。

## 2. 图像插值放大

仿射变换的反向映射阶段，我们拿到了一个**浮点**坐标 $(x, y)$。原图只有整点位置有值。那么问题来了：

> 浮点位置上的值怎么取？

这就是**插值**要解决的事。在"放大"场景下这个问题尤其突出——输出像素比输入像素多得多，绝大多数输出像素落在两个原像素之间。

### 2.1 最邻近插值算法

最简单粗暴的方法：**离浮点位置最近的整像素，拿来直接用**。

$$ I_{\\text{out}}(i', j') = I_{\\text{in}}\\bigl(\\lfloor x + 0.5 \\rfloor,\\; \\lfloor y + 0.5 \\rfloor\\bigr) $$

也就是四舍五入取整。

```python
def nearest_neighbor(img, x, y):
    """img: (H, W), (x, y): 浮点坐标"""
    xi = int(round(x))
    yi = int(round(y))
    if 0 <= xi < img.shape[1] and 0 <= yi < img.shape[0]:
        return img[yi, xi]
    return 0
```

**特性**：

- ⚡ **最快的**插值方法，没有之一
- 保留原始像素值，不做任何平滑
- 视觉效果：放大后出现明显的**块状锯齿**（blocky artifacts）

```
最近邻放大 3 倍的效果示意：
原图 2×2 →         放大后 6×6：
┌────┬────┐        ┌──┬──┬──┬──┬──┬──┐
│ ██ │    │        │██│██│██│  │  │  │
├────┼────┤        ├──┼──┼──┼──┼──┼──┤
│    │ ██ │        │██│██│██│  │  │  │
└────┴────┘        ├──┼──┼──┼──┼──┼──┤
                   │██│██│██│  │  │  │
                   ├──┼──┼──┼──┼──┼──┤
                   │  │  │  │██│██│██│
                   ├──┼──┼──┼──┼──┼──┤
                   │  │  │  │██│██│██│
                   ├──┼──┼──┼──┼──┼──┤
                   │  │  │  │██│██│██│
                   └──┴──┴──┴──┴──┴──┘
                         原来 4 个像素分别复制成了 3×3 的块
```

> 💡 **什么时候用最近邻？** 像素艺术放大（像素画风）、调色板化图像（颜色数是有限的离散集合）、二值图、分类结果的标签图。这些场景下插值出来的"中间值"没有意义，只有取原值才正确。

### 2.2 双线性插值算法

不想看到马赛克？那就做个**加权平均**——用浮点位置周围的 4 个整像素，按距离加权求值。

设 $(x, y)$ 周围四个整数点为：

$$
\\begin{aligned}
p_{00} &= I(\\lfloor x \\rfloor, \\lfloor y \\rfloor) \\\\
p_{10} &= I(\\lfloor x \\rfloor + 1, \\lfloor y \\rfloor) \\\\
p_{01} &= I(\\lfloor x \\rfloor, \\lfloor y \\rfloor + 1) \\\\
p_{11} &= I(\\lfloor x \\rfloor + 1, \\lfloor y \\rfloor + 1)
\\end{aligned}
$$

设 $dx = x - \\lfloor x \\rfloor$，$dy = y - \\lfloor y \\rfloor$（都在 $[0, 1)$ 内），则：

**第一步：在 x 方向上做两次线性插值**

$$
\\begin{aligned}
p_{0} &= p_{00} \\cdot (1 - dx) + p_{10} \\cdot dx \\\\
p_{1} &= p_{01} \\cdot (1 - dx) + p_{11} \\cdot dx
\\end{aligned}
$$

**第二步：在 y 方向上做一次线性插值**

$$
I(x, y) = p_{0} \\cdot (1 - dy) + p_{1} \\cdot dy
$$

展开后得到一个加权公式：

$$
\\begin{aligned}
I(x, y) = &\\; p_{00} \\cdot (1-dx)(1-dy) \\\\
         &+ p_{10} \\cdot dx(1-dy) \\\\
         &+ p_{01} \\cdot (1-dx)dy \\\\
         &+ p_{11} \\cdot dx\\,dy
\\end{aligned}
$$

```
双线性插值的几何直觉：

p00 ────────── p10
 │              │
 │    ● (x,y)   │   ← 深色点是要插值的位置
 │    dx=0.4    │
 │    dy=0.7    │
 │              │
p01 ────────── p11
```

```python
def bilinear(img, x, y):
    """img: (H, W), (x, y): 浮点坐标"""
    x0, y0 = int(np.floor(x)), int(np.floor(y))
    x1, y1 = x0 + 1, y0 + 1
    dx, dy = x - x0, y - y0

    # 边界裁剪
    x0 = max(0, min(x0, img.shape[1]-1))
    x1 = max(0, min(x1, img.shape[1]-1))
    y0 = max(0, min(y0, img.shape[0]-1))
    y1 = max(0, min(y1, img.shape[0]-1))

    v00 = img[y0, x0]
    v10 = img[y0, x1]
    v01 = img[y1, x0]
    v11 = img[y1, x1]

    # x 方向插值
    v0 = v00 * (1 - dx) + v10 * dx
    v1 = v01 * (1 - dx) + v11 * dx

    # y 方向插值
    return v0 * (1 - dy) + v1 * dy
```

**特性**：

- 👍 平滑、计算量适中（每个像素 ~10 次浮点运算）
- 👎 会丢失**高频细节**，看起来有点糊（相当于作用了一个低通滤波器）
- 放大倍数越大，模糊越明显（因为插值基底的间隔在放大）

> 💡 **DSP 视角**：双线性插值等价于用**三角核**（triangular kernel）做 2D 卷积后再采样。三角核的频域响应是 sinc²，主瓣宽、旁瓣弱——所以平滑性好但高频丢失。

### 2.3 三次卷积插值算法

想比双线性更锐利？用**三次多项式**作为插值核。

三次卷积（bicubic 或 cubic convolution）是最常用的高质量插值方案。它用浮点位置周围 **4×4 = 16 个**像素，用一个三次函数为每个像素赋予权重。

#### 一维三次插值核

核心是一个分段三次多项式函数（$a$ 是自由参数，常用 $a = -0.5$ 或 $a = -0.75$）：

$$
W(t) = \\begin{cases}
(a + 2)|t|^3 - (a + 3)|t|^2 + 1, & 0 \\le |t| \\le 1 \\\\
a|t|^3 - 5a|t|^2 + 8a|t| - 4a,  & 1 < |t| \\le 2 \\\\
0,                                 & |t| > 2
\\end{cases}
$$

其中 $t$ 是到采样点的距离。

参数 $a$ 控制旁瓣幅度：

- $a = -0.5$：**默认推荐值**，与真实 sinc 的泰勒展开匹配，适合自然图像
- $a = -0.75$：旁瓣更强，锐化效果更明显，但可能过冲
- $a = 0$：降级为三次 B 样条插值，最平滑

#### 二维执行

二维三次卷积可分离为：先在 x 方向对每行做 4 点三次插值，再在 y 方向对得到的 4 个中间值做三次插值。

```python
def cubic_kernel(t, a=-0.5):
    """一维三次卷积核"""
    t = abs(t)
    if t <= 1:
        return (a + 2) * t**3 - (a + 3) * t**2 + 1
    elif t <= 2:
        return a * t**3 - 5*a * t**2 + 8*a * t - 4*a
    return 0

def bicubic(img, x, y, a=-0.5):
    """img: (H, W), (x, y): 浮点坐标"""
    x0 = int(np.floor(x)) - 1  # 左移一位，周围 4 列
    y0 = int(np.floor(y)) - 1

    # 收集 4×4 邻域点
    val = 0.0
    for i in range(4):
        xi = x0 + i
        if xi < 0 or xi >= img.shape[1]:
            continue
        wx = cubic_kernel(xi - x, a)
        row_sum = 0.0
        for j in range(4):
            yj = y0 + j
            if yj < 0 or yj >= img.shape[0]:
                continue
            wy = cubic_kernel(yj - y, a)
            row_sum += img[yj, xi] * wy
        val += row_sum * wx
    return val
```

**特性**：

- 👍 比双线性**更锐利**，保留了更多高频细节
- 👍 旁瓣产生的负权重带来了**边缘增强**效果，视觉上更讨喜
- 👎 计算量大约是双线性的 4 倍（16 个像素 vs 4 个）
- 👎 旁瓣可能导致**过冲**（overshoot），出现亮边（ringing artifact）

#### 三种插值算法对比总结

| 方法 | 邻域大小 | 计算量 | 锐度 | 典型场景 |
|:---|:---:|:---:|:---:|:---|
| 最邻近 (Nearest) | 1 像素 | 极低 | 锯齿严重 | 像素艺术、标签图 |
| 双线性 (Bilinear) | 4 像素 | 低 | 平滑但糊 | 实时、视频缩放 |
| 三次卷积 (Bicubic) | 16 像素 | 中 | 锐利、有增强 | 照片缩放、高质量输出 |

> 💡 再往上有 **Lanczos**（用截断 sinc，接近理想重建，但计算量更大），再往下是深度学习超分辨率（SRCNN、ESPCN、EDSR 等）。三次卷积是工程上"质量-速度"的最优折中点，**作为默认缩放方案用了三十多年**，至今在 Photoshop、ImageMagick、浏览器渲染引擎里仍是主力。

## 3. 图像缩小

缩小（downsampling）和放大看似对称，但难点完全不同。放大是"猜中间值"，缩小是"不要混叠"。

从频域角度理解：缩小相当于**降低采样率**。如果原图有高于目标采样率一半的高频成分，就必然出现混叠（aliasing）。这和第一章讲的采样定理是**同一件事**——只不过现在是已知过采样信号，要合法地下采样。

### 3.1 基于等间隔采样的图像缩小

最直接的缩小方法：每隔 $k$ 个像素取一个。

假设缩小的比例是 $1/k$（即输出尺寸是输入的 $1/k$），则输出图中的 $(i', j')$ 对应输入图的 $(i' \\cdot k, j' \\cdot k)$：

$$
I_{\\text{out}}[i', j'] = I_{\\text{in}}[i' \\cdot k, \\; j' \\cdot k]
$$

```python
def subsample(img, k):
    """每隔 k 个像素取一个"""
    return img[::k, ::k]
```

```
等间隔采样 k=3 示意：

输入:  ┌──┬──┬──┬──┬──┬──┬──┬──┬──┐
       │a │b │c │d │e │f │g │h │i │
       ├──┼──┼──┼──┼──┼──┼──┼──┼──┤
       │j │k │l │m │n │o │p │q │r │
       ├──┼──┼──┼──┼──┼──┼──┼──┼──┤
       │s │t │u │v │w │x │y │z │ee│
       ├──┼──┼──┼──┼──┼──┼──┼──┼──┤
       ...

输出:  ┌──┬──┬──┐
       │a │d │g │
       ├──┼──┼──┤
       │j │m │p │
       ├──┼──┼──┤
       │s │v │y │
       └──┴──┴──┘
```

**问题**：

这是**最危险**的缩小方法。如果原图含有高于 $1/(2k)$（空间频率）的细节，**一定会 alias**：

```
     输入（细密条纹 1 像素周期）      等间隔采样 k=2    结果
     ┌─┬─┬─┬─┬─┬─┬─┬─┐              ┌─┬─┬─┬─┐
     │█│░│█│░│█│░│█│░│              │█│█│█│█│   ← 全部黑色？
     └─┴─┴─┴─┴─┴─┴─┴─┘              └─┴─┴─┴─┘
     黑白交替，周期为 2 像素          每隔 1 个取 1 个
                                     正好全取到黑色，原信息丢失！
```

> 💡 **什么时候能用等间隔采样？** 当输入信号已经被充分低通滤波（比如已经被缩小过的中间结果），或者原图就是你确信没有高频的简单内容（纯色块的文字截图）。否则——**不要冒险**。

### 3.2 基于局部均值的图像缩小算法

为了解决 alias，核心思路很简单：**下采样之前先低通**。这就是 DSP 里变采样率（decimation）的标准流程：先滤波，后抽取。

**局部均值**（区域平均 / 块平均 / box filter）是最简单的低通方式：把输入图上每个 $k \\times k$ 块内的像素取平均，作为输出图的一个像素。

$$
I_{\\text{out}}[i', j'] = \\frac{1}{k^2} \\sum_{p=0}^{k-1} \\sum_{q=0}^{k-1} I_{\\text{in}}[i' \\cdot k + p,\\; j' \\cdot k + q]
$$

```python
def local_mean_downsample(img, k):
    """块平均缩小，k 是缩小倍数"""
    H, W = img.shape
    H_out, W_out = H // k, W // k
    # 裁剪到能被 k 整除
    img_crop = img[:H_out * k, :W_out * k]
    # 变形并平均
    return img_crop.reshape(H_out, k, W_out, k).mean(axis=(1, 3))
```

```
块平均 k=3 示意：

每个 3×3 块加起来除以 9：

┌─────────┬─────────┬─────────┐
│ a  b  c │ d  e  f │ g  h  i │
│ j  k  l │ m  n  o │ p  q  r │
│ s  t  u │ v  w  x │ y  z 00 │
├─────────┼─────────┼─────────┤
│ ...     │ ...     │ ...     │
└─────────┴─────────┴─────────┘
     ↓ 每个块求平均
┌─────────┬─────────┬─────────┐
│  avg_1  │  avg_2  │  avg_3  │
├─────────┼─────────┼─────────┤
│ ...     │ ...     │ ...     │
└─────────┴─────────┴─────────┘
```

从频域看，box filter 等价于一个 2D sinc 低通滤波器。它的传递函数是：

$$
H(u, v) = \\text{sinc}(k u) \\cdot \\text{sinc}(k v)
$$

**不足之处**：sinc 的主瓣衰减不够快，旁瓣仍有一部分高频泄漏，所以**不是最理想的抗混叠滤波器**。但胜在简单、快速，对大多数自然图像已经够用。

#### 更好的方案：高斯滤波 + 采样

如果追求更高质量，可以用**高斯滤波器**先做低通，再等间隔采样：

```python
from scipy.ndimage import gaussian_filter

def gaussian_downsample(img, k, sigma=None):
    """高斯平滑后下采样"""
    if sigma is None:
        sigma = k / 3.0  # 经验值：sigma 与缩小倍数成正比
    smoothed = gaussian_filter(img, sigma=sigma)
    return smoothed[::k, ::k]
```

高斯核的频域响应也是高斯（平滑、无旁瓣），所以抗混叠效果比 box filter 好。代价是多一次卷积计算。

#### 等间隔采样 vs 局部均值对比

| 方法 | 抗混叠 | 计算量 | 锐度 | 推荐场景 |
|:---|:---:|:---:|:---:|:---|
| 等间隔采样 | ❌ 无 | O(1) | 最锐但 alias | 极少用 |
| 局部均值 | ✅ 基本 | O(N/k²) | 略糊 | 快速缩小 |
| 高斯+采样 | ✅ 好 | O(N·k) | 较清晰 | 艺术/高质量缩小 |

> 💡 **DSP 总结**：局部均值缩小 = box filter + 抽取。这和 DSP 里的 **CIC（Cascaded Integrator-Comb）滤波器**的第一级级联思路很像——先积累再抽取。数值上最廉价，抗 aliasing 够用。

> 如果追求极致质量，现代图像处理库里（如 Pillow、OpenCV、ImageMagick）缩小默认用的是 **Lanczos** 或 **bicubic 缩放** 配合高质量抗混叠，本质上是一个"先上采样到匹配频率、通过插值核做抗混叠滤波、再下采样"的复合过程。但那涉及滤波器的频域设计了，我们放到后面频域处理章节再深入。

## 收尾：把几何变换链路串起来

```
目标变换（旋转/缩放/平移...）
        │
        │ 写成齐次矩阵 M
        ▼
   仿射矩阵 M (3×3)
        │
        │ 求逆 M_inv
        ▼
   反向映射矩阵 M_inv
        │
        │ 遍历输出图的每个像素 (i', j')
        │ 用 M_inv 算出原图浮点位置 (x, y)
        ▼
   浮点坐标 (x, y)
        │
        │ 落在整像素之间 → 需要插值
        ▼
   ┌─ 最近邻（快，锯齿）
   ├─ 双线性（平滑）
   └─ 三次卷积（锐利）
        │
        ▼
   输出像素值
        │
        │ 重复直到填满输出图
        ▼
   变换后的图像
```

**核心思想一句话**：仿射变换决定"从哪取"，插值决定"怎么取"，下采样决定"别 alias"。

## 推荐自己动手试试

1. **手写仿射变换**：不用 OpenCV，用 NumPy 实现一个 90 度旋转变换（$\\cos 90^\\circ = 0, \\sin 90^\\circ = 1$），分别用最近邻和双线性插值实现反向映射，对比两张输出图。

2. **做图像金字塔**：对一张高分辨率照片，用局部均值缩小法生成 1/2、1/4、1/8 尺度的缩略图，然后用等间隔采样也做一个，对比哪个看起来噪声更少、aliasing 更轻。这就是**高斯金字塔**（Gaussian pyramid）的雏形。

3. **插值对比实验**：把一张小图（比如 50×50）通过最近邻、双线性、三次卷积分别放大到 400×400，并排显示，从眼睛、文字边缘等区域观察三种算法的区别。你会对"双线性糊在哪"、"bicubic 锐在哪"有实实在在的直观感受。

4. **玩 OpenCV 的参数**：用 `cv2.resize(img, dsize, interpolation=cv2.INTER_*)`，对比 `INTER_NEAREST`、`INTER_LINEAR`、`INTER_CUBIC` 的效果。
