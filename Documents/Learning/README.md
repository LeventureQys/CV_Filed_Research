# 数字图像处理 —— 学习路线

> 写给有 DSP 基础的资深工程师

## 背景与目标

你是有丰富工程经验的工程师，具备一定的 **数字信号处理（DSP）** 基础——这意味着你对采样定理、频域变换、滤波器设计这些核心概念有直觉，知道信号在时/频域之间切换意味着什么。这份基础是学图像处理的极好起点，因为图像本质上就是**二维信号**，很多 DSP 里的思维框架可以直接平移过来。

我们的目标不是"把教材过一遍"，而是**建立从信号处理直觉到计算机视觉算法的桥梁**：每讲一个概念，都讲清楚它和 DSP 中的对应概念有什么关系、为什么到了图像领域需要做不同的取舍。

## 教学风格

- **工程直觉优先**——不堆公式，但公式会到位。每个公式出现时都配一句话解释"它在说什么"
- **对比式学习**——反复把图像处理和 DSP 中对应的概念并排讨论，让你已有的知识能被复用
- **代码触手可及**——关键算法配有可运行的 Python 示意，鼓励你改参数看效果
- **常见陷阱明说**——那些"第一次遇到会让怀疑人生的坑"，会提前告诉你

## 如何阅读本文档

- 每章都是一个独立的 `.md` 文件，可直接在 VS Code / Obsidian 等支持 LaTeX 数学公式的 Markdown 渲染器中打开
- 内联公式用 `$...$`，独立公式用 `$$...$$`
- 建议**边读边打开 Python/OpenCV 终端**，遇到"自己动手试试"的环节就停下来跑几分钟
- 已完成的章节末尾会标注下一章的推荐链接
