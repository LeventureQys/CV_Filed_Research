# 数字图像处理 —— 原创学习路线

> 写给有 DSP 基础、希望系统入门计算机视觉工程的读者。

## 背景与目标

图像本质上是二维信号。你在 DSP 中熟悉的采样定理、频域变换、滤波器、系统响应、噪声建模——在图像处理中依然成立，只是从一维时间序列变成了二维空间阵列。

这套文档是原创教学，每章均以**图解 + 数值示例 + 用例 + 练习题**的方式深入讲解。正文不用代码，全部依靠公式推导、对比图、流程图和实际数据来建立直觉。

## 写作风格

- **数形结合**：每章配 3~5 张 Python 生成的高质量示意图（对比图、曲线图、流程图、数值演示）。
- **工程直觉优先**：每个概念都讲清楚"像 DSP 中的什么"、"为什么在图像里要这么处理"。
- **练习题 + 解答**：每章 3 道练习题，紧跟参考答案。
- **深入浅出**：不为简单而删减推导，不断章取义。

## 建议阅读顺序

按 01 → 15 顺序推荐，每章可独立阅读，但前后有自然依赖：
- 01-03：图像作为二维数组的坐标、值和变换基础。
- 04-06：信号处理核心——频域、增强、恢复。
- 07-10：视觉理解——分割、特征、形态学、识别。
- 11-14：存储、分形、加密与水印。
- 15：系统集成与工程闭环。
