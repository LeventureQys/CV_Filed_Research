# 力场重建用户操作指南

> 状态说明：本文操作步骤对应实物模型展示编辑器的现行参考行为。v1.0.9 beta4 C++ 目标算法见 [beta4最终方案.md](beta4最终方案.md)，目前仍处于设计完成、尚未开发状态。beta4 实现完成前，不应把本文中的欧氏距离传播行为当作新版本已经修复。

## 1. 功能是什么

力场预览把模型表面若干 Cell 的离散压力值，拟合为连续的表面颜色区域。颜色用于表达各位置的相对压力：通常蓝色较低，青/黄居中，红色较高；无有效覆盖或压力过低的区域保持灰色。

本功能用于布局验证、压力趋势演示和传感器覆盖检查。它**不会**计算应力、应变、位移或模型形变，因此不能替代有限元分析。

## 2. 操作前准备

### 2.1 导入模型

1. 通过“文件 → 导入模型”加载模型。
2. 查看模型属性中的单位比例，确认 `1 模型单位 = ? mm` 符合实际尺寸。
3. 若单位不正确，先修改单位比例，再放置 Cell。

力场半径使用毫米，程序内部会根据单位比例转换为模型单位。单位比例错误时，最常见现象是热区完全不显示、覆盖范围极小或覆盖整件模型。

### 2.2 放置 Cell

1. 点击“放置模式”。
2. 在模型曲面上单击放置 Cell。
3. 在主要受力区域和过渡区域都放置 Cell，避免采样只集中在一个小区域。
4. 放置完成后，再次点击“放置模式”退出。

Cell 是压力场的离散采样位置。Cell 越稀疏，重建越依赖较大的力场半径，结果也越偏向平滑趋势而非局部细节。

## 3. 手动输入压力并预览

1. 单击模型上的 Cell，或从 Cell 列表中选中它。
2. 在右侧属性面板的“压力值”输入 `0~1`：
   - `0`：无压力；
   - `0.5`：中等压力；
   - `1`：最大显示压力。
3. 为需要参与对比的 Cell 分别设置压力值。
4. 点击工具栏“力场预览”，或使用“视图 → 力场预览”。
5. 打开预览后，在“力场设置”中保持模式为“手动压力”。

输入值会被限制在 `0~1`。空值、非法文本和非有限数值按 `0` 处理。

## 4. 调节力场半径

“力场半径”表示每个 Cell 对周围模型顶点的最大影响距离，当前范围为 `20~200 mm`，默认值为 `60 mm`。

- 热区之间有明显空洞：适当增大半径。
- 相邻热点被过度混合：适当减小半径。
- Cell 间距大：半径通常需要更大。
- 需要突出局部压力差异：半径通常需要更小，但不能小到没有顶点落入覆盖区。

建议从“平均相邻 Cell 间距的 `1~2` 倍”开始调整，再根据实际模型观察连续性。修改半径会重建空间影响缓存，大模型可能出现短暂计算等待。

## 5. 使用模拟压力

点击“模拟压力”后，编辑器会切换到模拟模式并周期性更新 Cell 压力。模拟仅用于检查动态渲染、展示视觉效果，不代表真实外力或材料响应。

### 模拟预设

| 预设 | 行为 | 适用场景 |
|---|---|---|
| `Wave` | 不同 Cell 使用不同相位和频率变化 | 检查多个热点连续变化 |
| `Uniform` | 所有 Cell 同步变化 | 检查整体颜色响应一致性 |
| `Pulse` | 随机选择少量 Cell 形成周期脉冲热点 | 检查局部瞬时热点 |

再次点击“模拟压力”可停止模拟。若要恢复人工值控制，在力场设置的模式中选择“手动压力”。注意：模拟过程会写入 Cell 的 `pressure` 字段，因此切回手动模式后，应按需要重新填写人工压力值。

## 6. 如何理解显示结果

### 6.1 颜色不是力的叠加

每个 Cell 被视为连续压力场的一个采样值，而不是向外释放能量的“力源”。某个模型顶点的压力由附近 Cell 压力的加权平均得到，所以 Cell 密集区域不会仅因 Cell 数量更多而无条件变红。

### 6.2 灰色区域

以下情况会显示灰色：

- 顶点不在任何 Cell 的力场半径内；
- 重建压力低于当前可视阈值；
- 邻域权重置信度太低；
- Cell 压力均为 `0`。

### 6.3 显示的是相对值

当前颜色直接使用 `0~1` 压力值映射。若原始数据单位是 N、kPa 或 ADC 计数，必须先在外部归一化：

```text
normalized = clamp((value - min) / (max - min), 0, 1)
```

对多帧数据做比较时，应使用相同的 `min` 和 `max`，否则不同帧颜色不可直接比较。

## 7. 推荐用户行为

1. 先校准模型单位，再放置 Cell。
2. Cell 应贴合模型曲面，并覆盖预期受力区及其边界。
3. 先用统一压力值检查覆盖是否连续，再输入真实的相对压力。
4. 先用默认 `60 mm`，再依据 Cell 间距调半径。
5. 比较不同工况时保持 Cell 布局、力场半径和归一化范围一致。
6. 截图或导出结论前，停止模拟压力，确认当前数据来源。
7. 不要把热力图直接解释为材料内部应力或结构安全结论。

## 8. 常见问题

### 点击力场预览后没有颜色

- 确认至少放置了一个 Cell。
- 确认至少一个 Cell 的压力大于 `0`，建议先输入 `1` 验证。
- 确认 Cell 位于模型表面，而不是远离模型。
- 检查模型单位比例。
- 增大力场半径。

### 只有零散色块，过渡不连续

- 增大力场半径。
- 增加 Cell 数量并改善分布。
- 检查模型三角网格是否过于稀疏；颜色在顶点计算后由三角面插值，低面数模型的显示精度有限。

### 模型背面出现正面 Cell 的颜色

当前算法使用 3D 空间直线距离，不使用沿曲面的测地距离。薄壁、折叠或相互靠近的两层曲面可能发生跨面影响。可减小力场半径，或在数据处理/后续版本中增加法线、连通域或测地距离约束。

beta4 的目标行为是使用拓扑连通的表面最短路径，并让面片折角增加路径代价；不同连通分量之间不传播。该行为需在 beta4 阶段三实现和验收完成后生效。

### 修改 Cell 位置或半径后短暂卡顿

位置、Cell 数量或力场半径变化会使影响关系缓存失效，程序需要重新计算“顶点—Cell”关系。只修改压力值时会复用缓存，通常更快。

### 颜色看起来与旧文档不同

请以当前版本界面和本目录文档为准。历史 beta 文档中曾描述 `0~100` 范围、固定压力上下限或数据导入模式，这些不属于当前页面的用户行为。
