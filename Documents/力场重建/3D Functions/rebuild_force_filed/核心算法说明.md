# 力场重建核心算法说明

> 状态说明：本文描述从实物模型展示编辑器抽取的现行参考实现。v1.0.9 beta4 最终目标方案已在 [beta4最终方案.md](beta4最终方案.md) 中重新定义：Cell 仍采用采样值插值，但距离改为曲面路径，coverage 进入有效标量，并使用连续灰底色带。本文中的三维欧氏距离、邻接平滑和 RGB coverage 混合不能视为 beta4 最终设计。

## 1. 实现边界

当前功能是“离散表面采样值 → 网格顶点标量 → 顶点色”的可视化重建管线：

```text
Cell 坐标 + pressure(0~1)
        ↓
空间分桶查询邻域 Cell
        ↓
Wendland C2 局部加权平均
        ↓
网格邻接平滑（1 次）
        ↓
置信度与低值阈值处理
        ↓
Jet 色图 + 模型灰色混合
        ↓
Three.js geometry.attributes.color
```

它不是刚体/柔体动力学、有限元或接触力学求解器。模型形状和顶点位置不因压力发生改变。

## 2. 输入与坐标

每个 Cell 至少包含：

```js
{
  id: 12,
  x: 1.2,
  y: 3.4,
  z: 5.6,
  pressure: 0.75,
  r: 10
}
```

- `x/y/z`：Cell 空间中的模型局部坐标。
- `pressure`：归一化压力，现行 UI 限制为 `0~1`。
- `r`：Cell 自身显示半径，单位为 mm；它不等于力场影响半径。
- `FIELD_R`：全局力场影响半径，单位为 mm，默认 `60`。
- `unitMM`：每个模型单位对应的毫米数，内部通过 `fieldRadiusU = FIELD_R / unitMM` 转换。

模型顶点先经模型世界矩阵，再转换到与 Cell 一致的局部空间，结果缓存于 `_vpos`。距离使用三维欧氏距离：

$$
d_i(v)=\sqrt{(x_v-x_i)^2+(y_v-y_i)^2+(z_v-z_i)^2}
$$

## 3. Wendland C2 核

对影响半径 $R$ 内的 Cell，定义归一化距离 $r_i=d_i/R$：

$$
\phi(r)=
\begin{cases}
(1-r)^4(4r+1), & 0\le r<1\\
0, & r\ge 1
\end{cases}
$$

关键性质：

- 紧支撑：超过半径后权重严格为零，便于局部查询和缓存。
- 中心权重为 1：顶点越接近 Cell，权重越大。
- 边界平滑：在支撑边界自然衰减到零，避免硬截断。

## 4. 标量场重建

顶点 $v$ 的基础压力为邻域 Cell 压力的归一化加权平均：

$$
P(v)=\frac{\sum_i p_i\phi(r_i)}{\sum_i\phi(r_i)}
$$

分母归一化很重要：它使结果表达附近采样值的插值，而不是多个 Cell 的压力总和。若邻域权重和小于 `1e-6`，该顶点不产生有效压力。

现行代码只把 `pressure` 作为标量输入。代码中保留了虚拟锚点函数 `getVirtualAnchors()`，但当前主重建路径没有调用它，因此不能把虚拟锚点描述为已生效算法。

## 5. 邻接平滑

程序从三角面建立顶点邻接表，然后执行 1 次局部平滑：

$$
P'_{v}=0.7P_v+0.3\frac{\sum_{u\in N(v)}w_{vu}P_u}{\sum_{u\in N(v)}w_{vu}}
$$

邻接权重主要与边长平方的倒数相关，并尝试使用顶点法线点积降低尖角两侧的串色。其目的不是重新求解压力场，而是减少低面数网格上相邻顶点颜色的突变。

## 6. 置信度和着色

每个顶点的覆盖置信度为：

$$
c(v)=\min\left(1,\sum_i\phi(r_i)\right)
$$

现行着色规则：

- `c <= 0.01`：保持模型灰色。
- `P <= 0.04`：保持模型灰色。
- `0.04 < P < 0.25`：Jet 颜色按较低透明强度与灰色混合。
- `P >= 0.25`：Jet 颜色按 `c × 0.65` 与灰色混合。

因此即使 `pressure=1`，最终模型颜色也不是纯 Jet 红色，而是与灰色底色混合后的结果。中心点标记本身则直接使用 Jet 色图。

## 7. 性能结构

### 7.1 空间分桶

桶边长等于力场半径。Cell 按三维网格分桶，查询一个顶点时只访问本桶和相邻 26 个桶，将朴素的全量 Cell 搜索缩小为局部候选搜索。

### 7.2 CSR 影响缓存

Cell 位置和力场半径不变时，“哪个 Cell 影响哪个顶点”以及对应核权重不变。程序用类似 CSR 的数组保存关系：

| 缓存 | 含义 |
|---|---|
| `_vpos` | 所有模型顶点在 Cell 空间中的坐标 |
| `_ioff` | 每个顶点影响项在扁平数组中的起止偏移 |
| `_icell` | 每个影响项对应的 Cell ID |
| `_iwgt` | 每个影响项的 Wendland 权重 |
| `_cv` | 至少被一个 Cell 覆盖的顶点索引 |
| `_adj` | 网格顶点邻接关系 |

这样，压力变化时只需重新执行加权平均、一次平滑和着色，不必重新计算距离与核函数。

### 7.3 缓存失效条件

- Cell 增加、删除、移动；
- 力场半径变化；
- 模型更换；
- 影响坐标关系发生变化。

仅修改 Cell 压力时不重建影响缓存。`updateHeatmap._lastKey` 还会避免压力集合完全相同时重复着色。

## 8. 网格预处理

顶点色最终由三角形内部插值。若原始三角形边长大于 `FIELD_R / 4`，且原始面数少于 `80000`，导入时会自动尝试细分：

- 最多 3 次迭代；
- 目标上限约 `200000` 面；
- 目的只是提高颜色采样密度，不改变压力重建公式。

## 9. 模拟压力

模拟模式直接周期性写入 Cell 的 `pressure`：

- `Uniform`：全部 Cell 同步正弦变化；
- `Wave`：按 Cell ID 生成不同相位与频率；
- `Pulse`：随机热点按 $\sin^2$ 脉冲变化，其他 Cell 使用低背景值。

更新周期常量为 `40 ms`，压力场着色通常每 `80 ms` 调用一次。模拟结果仅用于展示和渲染验证。

## 10. 已知局限

1. 使用欧氏距离而非曲面测地距离，薄壁或相邻曲面可能跨面串色。
2. 压力值需预先归一化为 `0~1`，当前没有物理单位标定层。
3. 热图分辨率受网格顶点密度限制。
4. 邻接平滑会略微削弱局部尖峰。
5. 法线加权实现应在后续维护中单独验证，当前代码对读取到的法线分量再次乘以 3，不应把它视为严格的几何双边滤波实现。
6. 当前界面没有实时设备数据流接口；接入真实数据时，应只更新 Cell 压力并复用影响缓存。

## 11. 抽取代码

[force_field_core.js](force_field_core.js) 提供纯 JavaScript 参考实现，包括核函数、空间分桶、影响缓存和标量重建，不依赖 Three.js 或 DOM。它刻意不包含 UI、材质、定时器和模型坐标变换，便于在其他渲染器或测试环境中复用。

生产实现仍以 `src/3D编辑器原型.html` 为准。

## 12. beta4 迁移结论

beta4 对本参考算法的保留与替换如下：

| 项目 | beta4 处理 |
|---|---|
| Cell 是离散采样点 | 保留 |
| Wendland C2 核 | 保留 |
| `Σ(value × weight) / Σ(weight)` | 保留 |
| 三维欧氏距离 | 替换为带折角代价的网格表面路径 |
| 空间分桶查询 | 替换为表面图和截断 Dijkstra 影响缓存 |
| coverage 只混合 RGB | 替换为 coverage 乘入有效标量 |
| 网格邻接后置平滑 | beta4 不采用无约束后置平滑 |
| 低值硬阈值/灰色截断 | 替换为连续灰底色带 |
| 模型与图例分别处理 | 替换为同一公共 3D 色表 |

详细公式、默认参数和验收标准见 [beta4最终方案.md](beta4最终方案.md)。
