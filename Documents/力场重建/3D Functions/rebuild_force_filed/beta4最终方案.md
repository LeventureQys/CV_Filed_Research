# beta4 3D 曲面力场重建最终方案

## 1. 文档定位

本文汇总 v1.0.9 beta4 阶段一与阶段二形成的最终结论，用于说明后续 C++ 3D 实物模式应实现的目标算法。

本目录中各材料的状态如下：

- `force_field_core.js`：从实物模型展示编辑器抽取的现行参考实现，不是 beta4 最终算法。
- `核心算法说明.md`：说明编辑器现行的三维欧氏距离、Wendland 加权平均和颜色混合行为。
- 本文：beta4 已确认的目标语义、数学公式、曲面传播、配色和验证标准。
- C++ 详细接口和开发任务以父目录的 `设计文档.md`、`开发文档/`、`验收文档.md` 为准。

当前状态：方案已完成设计，尚未进入阶段三开发。本文描述的是目标行为，不表示生产代码已经具备这些能力。

## 2. 最终业务定义

### 2.1 Cell 是力场采样点

每个 Cell 表示连续真实力场在该位置的一次离散采样，不是向周围释放影响的独立力源。

因此，多个 Cell 的示数不能直接相加。重建结果表达的是对未采样表面位置的力值估计，而不是多个 Cell 的合成力。

### 2.2 等值采样点不会产生额外峰值

若四个相邻 Cell 的示数相同，中间区域原则上应保持相同值，不应仅因 Cell 数量更多而高于这些采样值。

例如四个 Cell 的值均为 `100`，中心对四个 Cell 的权重均为 `0.5`：

```text
interpolated = (100×0.5 + 100×0.5 + 100×0.5 + 100×0.5)
               / (0.5 + 0.5 + 0.5 + 0.5)
             = 100
```

这属于正确的采样插值行为，不是算法缺陷。若真实力场在采样点之间存在未采到的峰，仅凭现有采样无法可靠恢复；需要增加采样密度或引入有依据的物理模型。

### 2.3 beta4 不做的事情

- 不使用 `Σ(value × weight)` 作为最终值。
- 不制造高于邻域采样最大值的视觉假峰。
- 不执行有限元、材料应力、应变或形变计算。
- 不把模型颜色解释为真实结构应力。

## 3. 与 2D 实物模式的关系

2D 实物模式的核心计算位于 `src/render/wendland_field.h`。beta4 3D 方案采用与它相同的采样插值和 coverage 语义，但使用适合三角曲面的距离。

### 3.1 共同公式

对表面位置或顶点 `v`：

```text
interpolated(v) = Σ(value_i × weight_i(v)) / Σ(weight_i(v))
coverage(v) = clamp(Σ(weight_i(v)), 0, 1)
effective(v) = minValue + (interpolated(v) - minValue) × coverage(v)
```

- `interpolated`：根据附近采样估计的局部值。
- `coverage`：当前位置被采样覆盖的可信度。
- `effective`：用于颜色显示的有效值；覆盖边缘会连续回落到图例下限。

### 3.2 为什么 2D 的层次更明显

2D 现行实现把 coverage 直接乘入相对标量值，因此从 Cell 中心到覆盖边缘会经过完整的低、中、高色阶。

现行 3D 实现先计算加权平均，再用 coverage 在“模型灰”和“同一个热色”之间混合。若附近 Cell 数值相同，整个区域会选择同一个色相，只改变颜色浓淡，容易呈现大块均匀区域。

beta4 改为先计算 `effective`，再直接查询色表，不在 RGB 阶段第二次乘 coverage。

### 3.3 2D 与 3D 的必要差异

| 项目 | 2D 实物模式 | beta4 3D 实物模式 |
|---|---|---|
| 采样语义 | 加权平均插值 | 加权平均插值 |
| 核函数 | Wendland C2 | Wendland C2 |
| coverage | 乘入有效标量 | 乘入有效标量 |
| 距离 | 平面欧氏距离 | 网格表面最短路径代价 |
| 边界 | 二维布局 mask | 网格连通分量与支撑半径 |
| 折角 | 不适用 | 折角增加路径代价 |
| 后处理 | 可选二维高斯 | 不做无约束曲面后置平滑 |
| 色带 | 现有 Jet | 3D 专用连续灰底色带 |

## 4. Wendland C2 核

beta4 保留 Wendland C2 紧支撑核：

$$
\phi(r)=
\begin{cases}
(1-r)^4(4r+1), & 0\le r<1\\
0, & r\ge 1
\end{cases}
$$

其中：

```text
r = surfacePathCost / influenceRadius
```

核函数本身不是现行 3D 大块均匀的根因。根因主要是：

1. 现行算法使用三维欧氏距离，影响会穿过模型实体或跨越相邻曲面。
2. coverage 只用于 RGB 灰色混合，没有形成完整色阶的有效标量。
3. 低端色表使用整段硬灰截断，在阈值处产生颜色突变。

## 5. 曲面拓扑

### 5.1 为什么不能继续使用三维欧氏距离

三维欧氏距离只关心空间直线距离。对于薄壁模型，正面和背面可能只有几毫米间隔，但沿真实表面到达背面可能需要绕过较长边界。欧氏距离会把正面 Cell 直接映射到背面。

法线角度过滤也不能完整解决问题：两层平行曲面的法线可能方向接近，空间上相邻但拓扑上完全断开。

### 5.2 顶点焊接

STL 三角面通常按面展开，相邻面重复保存相同坐标的顶点。beta4 先按小容差焊接重复顶点，再建立共享边和邻接图。

```text
weldTolerance = max(
    boundsDiagonal × clamp(weldToleranceRatio, 1e-9, 1e-4),
    1e-7
)
```

默认：

```text
weldToleranceRatio = 1e-7
```

只合并欧氏距离不大于容差的顶点，不跨越正常薄壁厚度。模型本身存在真实裂缝时，裂缝两侧保持断开。

### 5.3 连通分量

焊接后根据共享三角边建立无向图，并计算连通分量。

- 同一连通分量内允许沿表面传播。
- 不同连通分量之间严格禁止传播。
- 空间上相邻的独立零件不会互相串色。

## 6. Cell 附着到曲面

`.3dlp` 中的 Cell 保存中心和法线，但没有三角面 ID。beta4 在影响缓存构建时执行：

1. 计算 Cell 中心到每个有效三角形的最近点。
2. 优先选择距离最近的三角形。
3. 距离在焊接容差内相同时，优先选择法线与 Cell 法线更一致的三角形。
4. 以投影点到该三角形三个焊接顶点的距离作为表面路径查询的初始代价。

使用三个初始顶点而非单一最近顶点，可以降低三角网格密度和顶点位置对结果的影响。

## 7. 表面路径与折角衰减

### 7.1 截断 Dijkstra

每个 Cell 从附着三角形出发，在网格图上执行半径截断的 Dijkstra：

- 只扩展累计路径代价不大于影响半径的顶点。
- 每个焊接顶点保留最小路径代价。
- 超过影响半径的顶点不进入影响缓存。

因此传播沿真实表面进行，不走穿过模型内部的空间捷径。

### 7.2 折角代价

共享边两侧三角面的夹角越大，跨越该边的路径代价越高：

```text
theta = acos(clamp(abs(dot(normal0, normal1)), 0, 1))
edgeCost = edgeLength × (1 + foldPenalty × (theta / pi)^2)
```

默认：

```text
foldPenalty = 2.0
```

效果：

- 共面或平滑曲面：代价接近真实边长。
- 明显折角：有效距离增加，Wendland 权重降低。
- 尖锐折角：远侧可能因代价超过支撑半径而不受影响。

使用 `abs(dot)` 是为了避免 STL 三角面绕序或法线朝向翻转把平滑面误判为 180° 折角。实际法线由三角形几何重新计算，不直接信任 STL 文件法线。

## 8. 最终标量重建

对每个焊接顶点，缓存所有能够沿表面到达该顶点的 Cell 及其 Wendland 权重。

### 8.1 加权平均

$$
P(v)=\frac{\sum_i p_i\phi(d_i/R)}{\sum_i\phi(d_i/R)}
$$

其中：

- $p_i$：第 `i` 个 Cell 的采样值。
- $d_i$：Cell 到顶点的曲面路径代价。
- $R$：影响半径。

该公式保证：

- 常量采样重建为常量场。
- 重建值原则上保持在有效邻域采样值范围内。
- 增加等值采样点不会无依据提高数值。

### 8.2 coverage

$$
C(v)=\min\left(1,\sum_i\phi(d_i/R)\right)
$$

### 8.3 用于显示的有效值

$$
E(v)=V_{min}+[P(v)-V_{min}]C(v)
$$

归一化颜色位置：

$$
t(v)=clamp\left(\frac{E(v)-V_{min}}{V_{max}-V_{min}},0,1\right)
$$

若 `maxValue <= minValue`，实现使用安全范围 `1.0`，不得崩溃。

若 Cell 值索引缺失，按 `minValue` 处理，而不是固定按 `0`，以保证非零图例下限的语义正确。

## 9. 3D 专用连续色带

beta4 不修改全局 Jet，也不修改 2D 色带。3D 模型和 3D 图例共同使用以下固定色标：

| 归一化位置 | RGB | 颜色含义 |
|---|---|---|
| 0.00 | 140, 140, 148 | 模型基底灰 |
| 0.12 | 32, 76, 180 | 深蓝 |
| 0.35 | 0, 190, 220 | 青 |
| 0.60 | 245, 220, 55 | 黄 |
| 0.80 | 245, 125, 35 | 橙 |
| 1.00 | 220, 35, 35 | 红 |

色标之间按 RGB 线性插值，生成 256 项色表。

### 9.1 与现行颜色策略的区别

现行 C++ 3D 色表把低端约 10% 全部替换为同一灰色，随后突然进入 Jet 蓝色。beta4 取消整段硬灰阈值：

- 无覆盖或有效值为图例下限时是模型灰。
- 低值从模型灰连续进入深蓝。
- 中高值使用更高饱和度的青、黄、橙、红，增强分层。
- 模型和图例调用同一色表函数，不允许图例与模型使用不同映射。

### 9.2 不做第二次 RGB coverage 混合

coverage 已经进入 `effective` 标量。颜色阶段只根据 `t` 查表，不再执行：

```text
grey × (1-coverage) + heatColor × coverage
```

避免同一个 coverage 被使用两次，也避免覆盖区域只改变颜色浓淡、不经过完整色阶。

## 10. 后置平滑

beta4 3D 不增加无约束的网格高斯平滑或邻接颜色平均。

原因：

- 后置平滑可能重新跨越尖锐折角。
- 不正确的顶点邻接可能跨过接缝或薄壁。
- 平滑会削弱真实采样差异。

连续性由以下机制共同提供：

1. 表面最短路径。
2. Wendland C2 平滑衰减。
3. coverage 边缘回落。
4. 三角形内部的顶点色插值。

## 11. 缓存结构与失效条件

### 11.1 缓存内容

建议缓存：

```text
expandedToWelded[triangleCount × 3]
offsets[weldedVertexCount + 1]
sampleIndices[influenceCount]
weights[influenceCount]
coveredWeldedVertices[]
```

- `expandedToWelded`：把焊接顶点颜色恢复到原 field VBO 顺序。
- CSR 影响缓存：保存每个焊接顶点受哪些 Cell 影响及固定权重。

### 11.2 必须重建缓存

- 模型或三角面变化。
- Cell 数量、位置或法线变化。
- 影响半径变化。
- 焊接容差或折角惩罚变化。

### 11.3 不重建缓存

- 实时 Cell 数值变化。
- 图例最小值、最大值或单位变化。
- 只重新映射颜色的显示变化。

实时帧更新只执行加权平均、coverage、色表查询和展开颜色，不重新运行顶点焊接或 Dijkstra。

## 12. 错误与降级行为

- 空模型、空 Cell、无有效三角形：缓存构建失败，模型保持灰色，不崩溃。
- 找不到 Cell 附着面：该 Cell 不建立影响项，记录一次 warning。
- 无效坐标或退化三角形：构建失败或安全跳过，不能返回错位的展开颜色。
- 色表不足 256 项或输出指针为空：着色返回失败。
- OpenGL 尚未初始化：只保存项目和状态，待 context 可用后构建 VBO。
- 缓存失败：Cell overlay 和其他 3D 交互仍可工作。

## 13. 性能目标

以 Debug 构建、代表性项目为准：

| 场景 | 目标 |
|---|---|
| 10 万三角形、64 Cell 首次表面图与影响缓存 | 不超过 3 秒 |
| 缓存建成后的单帧颜色更新 | 不超过 50 ms |

性能优化可以增加空间索引、优先队列优化和工作缓冲区复用，但不得退回纯欧氏距离，也不得改变采样插值语义。

## 14. 最终验收要点

### 数值

- 等值 Sample 的常量场不因 Sample 数量增加而升高。
- 不同 Sample 的插值保持在邻域值域内。
- coverage 使有效值从中心连续回落到图例下限。

### 几何

- 拓扑断开的薄壁背面不受正面 Sample 影响。
- 90° 折角路径代价大于共面路径。
- 折角路径的 Wendland 权重小于共面路径。

### 颜色

- 色表恰好 256 项。
- 首项为 `(140,140,148)`，末项为 `(220,35,35)`。
- 颜色从灰连续进入深蓝、青、黄、橙、红。
- 模型和图例相同归一化值使用相同色相。

### 集成

- 帧更新不重建表面图和影响缓存。
- 实际启动应用、加载 `.3dlp`、进入 3D 实物模式并更新数据无崩溃。
- 无与改动相关的 qCritical 或 spdlog ERROR。

完整验收步骤见父目录：

- `../验收文档.md`
- `../验收清单.md`

## 15. 最终结论

beta4 的最终方案不是“把多个 Cell 力值相加”，而是：

```text
力场采样值
    ↓
Cell 附着到三角曲面
    ↓
拓扑连通的截断表面最短路径
    ↓
折角增加路径代价
    ↓
Wendland C2 权重
    ↓
归一化采样值插值
    ↓
coverage 形成边缘衰减
    ↓
连续灰底高饱和色带
    ↓
模型与图例一致显示
```

该方案保留采样数据的可解释性，复用 2D 实物模式已验证的 coverage 层次，同时从距离定义上解决 3D 模型背面和跨曲面串色问题。
