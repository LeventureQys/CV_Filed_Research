本目录从当前 3D 拟物 Layout 编辑器中抽取压力/力场重建逻辑，说明用户如何操作，以及开发者如何理解和复用核心算法。

## 当前实现结论

- 当前生产实现位于 `src/3D编辑器原型.html` 的“Wendland 力场重建”代码段。
- 输入是贴在模型表面的 Cell 坐标和每个 Cell 的 `pressure`，压力有效范围为 `0~1`。
- 输出是模型各顶点的颜色；模型不会发生物理形变，也不是有限元力学仿真。
- 重建采用 3D 欧氏距离和 Wendland C2 紧支撑核的局部加权平均。
- 当前用户可使用“手动压力”和“模拟压力”两种模式；当前界面没有实时传感器数据导入模式。
- 热力图质量依赖模型顶点密度。导入低面数模型时，程序会在满足条件时自动细分几何体。

## beta4 最终结论

- Cell 已确认是连续力场的离散采样点，不是独立力源。
- beta4 保留归一化加权平均，不采用多个 Cell 数值直接相加。
- beta4 参考 2D 实物模式，将 coverage 乘入有效标量，使覆盖边缘经过完整色阶回落。
- beta4 使用拓扑连通的表面最短路径，并让折角增加路径代价，避免正面直接映射到薄壁背面。
- beta4 使用从模型灰连续进入深蓝、青、黄、橙、红的 3D 专用色带，模型与图例共用映射。

完整公式、默认参数、缓存和验收指标见 [beta4最终方案.md](beta4最终方案.md)。

## 最短操作路径

1. 导入 STL/OBJ/GLTF 模型，并确认模型单位比例正确。
2. 开启“放置模式”，在模型表面放置多个 Cell。
3. 选中 Cell，在属性面板将“压力值”设为 `0~1`。
4. 点击“力场预览”。
5. 在力场设置中调节“力场半径”；或点击“模拟压力”查看动态效果。

详细行为、参数选择和故障排查见 [用户操作指南.md](用户操作指南.md)。
